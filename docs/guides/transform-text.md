# 변형·텍스트·자·스탬프

**이 문서를 읽으면** 그림을 옮기고 늘리고 돌리고, 글자를 레이어로 쓰고, 자로 선을 맞추고, 장식과 무늬를 찍을 수 있습니다.

## 변형

이동·변형 도구(`V`, `Ctrl+T`)는 선택한 영역을 떠 있는 그림으로 들어 올려 옮기고, 늘리고, 돌립니다. 선택이 없으면 레이어 전체가 대상입니다. 확정하기 전까지 레이어 픽셀은 바뀌지 않습니다.

### 변형 모드

| 모드 | 하는 일 |
|---|---|
| 확대·축소·회전 | 모서리를 끌어 크기를 바꿉니다. 모서리 바깥을 끌면 회전합니다. `Shift`는 비율을 풀고, 회전은 15도 단위가 됩니다. `Alt`는 중심 기준입니다 |
| 자유 변형 | 네 모서리를 따로 움직입니다 |
| 워프 | 격자점을 끌어 면을 휩니다. 격자는 3×3, 4×4, 5×5 중에서 고릅니다 |

변형 막대에는 모드 세 개, `좌우 반전`, `상하 반전`, 워프일 때만 격자 세 개, `확정`, `취소`가 있습니다. 폭이 좁으면 묶음 단위로 줄이 바뀝니다.

- 확정은 `Enter`, 취소는 `Esc`입니다. 확정은 `변형` 한 단계로 되돌립니다.
- 다른 도구를 고르면 변형이 확정됩니다. 변형 중에는 다른 레이어를 고를 수 없습니다. 먼저 `Enter`나 `Esc`를 누릅니다.
- 잠긴 레이어, 폴더, 알파 잠금 레이어, 마스크 면, 퀵 마스크에서는 변형을 시작할 수 없습니다. 상태 줄에 이유가 나옵니다.

### 3D에 화면 기준으로 붙이기

Scene 뷰 우클릭 메뉴의 `이미지 추가…`를 고르면 그림 파일을 고르고, 그림을 Scene 뷰에서 본 모델 표면에 투영되는 변형 상자가 열립니다. 첫 프레임은 Scene 뷰 가운데에 놓이고, 화면의 60%보다 크면 줄어듭니다. 카메라를 돌려도 그림은 처음 본 각도 그대로 붙습니다.

## 복사, 잘라내기, 붙여넣기

| 명령 | 기본 키 | 하는 일 |
|---|---|---|
| 복사 | `Ctrl+C` | 선택 영역의 픽셀을 밍페인터 클립보드에 넣습니다. 레이어는 바뀌지 않습니다 |
| 잘라내기 | `Ctrl+X` | 복사하고 같은 자리를 지웁니다. 한 단계로 되돌릴 수 있습니다 |
| 붙여넣기 | `Ctrl+V` | 클립보드 그림을 현재 레이어 위에 변형 가능한 상태로 붙입니다. 확정하면 `붙여넣기` 한 단계입니다 |

- 밍페인터 클립보드는 프로그램 안에서만 씁니다. 운영체제 클립보드가 아닙니다.
- 잘라내기는 잠긴 레이어와 알파 잠금 레이어에서 거부됩니다. 퀵 마스크 중에는 복사와 잘라내기가 거부됩니다.
- 클립보드가 비어 있으면 `붙여넣을 내용이 없습니다. 먼저 복사하세요`가 나옵니다.

### 이미지 추가

이미지 파일을 새 레이어로 가져와 변형 상태로 붙입니다. 두 가지 메뉴가 있습니다.

- `이미지 추가…`: 모델 위에 붙입니다. 위의 3D 투영을 씁니다.
- `이미지를 UV에 붙이기…`: UV 텍셀 평면에 붙입니다.

두 메뉴는 Scene 뷰와 UV 캔버스의 우클릭 메뉴에 있습니다. PNG, JPG, TGA, BMP, GIF(첫 프레임)를 읽습니다. 긴 변이 8192 픽셀을 넘으면 실패합니다. WebP는 지원하지 않습니다. 기록에는 `이미지 추가`로 남습니다.

## 텍스트

텍스트 도구(`T`)는 캔버스를 누르면 입력을 시작합니다. 확정하면 글자 레이어가 됩니다. 글자 창은 입력을 시작할 때 함께 열립니다.

### 글자 창

| 블록 | 하는 일 |
|---|---|
| 범위 | `선택한 글자에 적용` 또는 `이어 쓸 글자에 적용 (선택 없음)`. 선택한 글자의 값이 다르면 `글자마다 값이 다릅니다`가 나옵니다 |
| 서체 | 검색 칸이 있는 목록입니다. 첫 항목은 기본 서체입니다. 목록에 없는 서체는 기본 서체로 그립니다 |
| 크기, 색, 굵게, 기울임 | 범위에 맞는 글자에만 적용합니다 |
| 세로쓰기, 경로 따라 쓰기 | 세로로 쓰거나, 그린 선을 따라 씁니다 |
| 줄 간격, 글자 간격, 정렬 | 줄 사이, 글자 사이, 왼쪽·가운데·오른쪽 정렬입니다. 세로쓰기에서는 위·가운데·아래입니다 |
| 테두리 | 굵기와 색 |
| 확정, 취소, 래스터화 | 아래 `확정과 래스터화`를 봅니다 |

- 글자를 선택하면 선택한 런에서 사용자가 바꾼 항목 하나만 바뀝니다. 다른 색이나 크기는 그대로 남습니다.
- 선택이 없으면 이어 쓸 글자에 적용됩니다.

![글자 창 좁은 폭](/img/captures/text-window-narrow.png)

### 입력과 키

- 입력 중인 IME 조합 글자는 밑줄로 보이며, 확정 전까지 글자 레이어에 들어가지 않습니다. 밑줄과 캐럿은 UV 캔버스에만 보입니다.
- `Ctrl+Enter`는 확정입니다. `Esc`를 두 번 누르면 취소입니다. 첫 `Esc`는 입력을 멈춥니다. 상태 칩에 현재 키가 나옵니다.
- 입력한 글자가 없으면 레이어를 만들지 않습니다.

![글자 입력과 캐럿](/img/captures/text-caret-uv.png)

### 세로쓰기와 경로 따라 쓰기

- 세로쓰기에서 한글, 한자, 가나는 세워 쓰고, 라틴 문자와 숫자는 눕혀 씁니다.
- `경로 따라 쓰기`를 켜고 Scene 뷰의 모델 표면이나 UV 캔버스에서 끌면 선이 그려지고, 글자가 그 선을 따라 놓입니다. 선이 너무 짧으면 `경로가 너무 짧습니다`가 나옵니다. 모델 표면이 없는 곳을 누르면 `클릭한 곳에 모델 표면이 없습니다`가 나옵니다.

### 확정과 래스터화

- `Ctrl+Enter`로 확정하면 글자 레이어가 됩니다. 글자 레이어는 글자 데이터를 가지고 있어 다시 고칠 수 있습니다.
- `래스터화` 단추는 글자 레이어를 일반 픽셀로 바꿉니다. 바꾼 뒤에는 글자를 고칠 수 없습니다.
- 글자 위에 픽셀을 그린 뒤 다시 확정하면 글자를 새로 그리면서 그 픽셀이 사라집니다. 상태 줄이 이를 알려 줍니다.
- 글자는 색 레이어에만 씁니다. 마스크 편집과 퀵 마스크 중에는 쓸 수 없습니다.
- 서체를 찾지 못하면 다른 서체로 그리고 `서체를 찾지 못해 다른 서체로 그렸습니다`를 알려 줍니다.

## 자

자 도구는 그림 선을 곧은 선, 곡선, 평행선, 동심원, 방사선에 맞춥니다. 자 종류는 서브툴 다섯 개입니다.

| 자 | 모양 |
|---|---|
| 직선자 | 두 점을 지나는 직선입니다. 뷰 가장자리까지 뻗습니다 |
| 곡선자 | 찍은 점들 사이를 지나는 곡선입니다 |
| 평행선자 | 평행선 가이드를 그립니다 |
| 동심원자 | 동심원 가이드를 그립니다 |
| 방사선자 | 한 점에서 나가는 방사선 가이드를 그립니다 |

### 만들기와 옮기기

- 자 도구로 화면을 누른 채 끌면 자가 만들어집니다. 자가 없으면 칩에 `자가 없습니다. 자 도구로 화면에 그려 만듭니다`가 나옵니다.
- 자의 핸들을 끌면 자가 옮겨집니다.
- 자는 뷰마다 하나입니다. Scene 뷰에 하나, UV 캔버스 문서마다 하나입니다. 편집 세션 안에만 남고 `.mpd` 파일에는 저장되지 않습니다.

### 모드 칩과 흡착

- 자가 있으면 위 가운데 칩이 나옵니다. 칩을 누를 때마다 `자 표시` → `자 표시 + 흡착` → `자 끔` 순서로 바뀝니다. 단축키는 `Ctrl+Alt+R`입니다.
- 흡착을 켜면 칠하는 획의 점이 자에서 16 픽셀 안에 있을 때 자 위로 옮겨집니다. UV 캔버스에서는 텍셀 기준입니다.

## 데코·스탬프·무늬

데코·스탬프·무늬 도구에는 기본 키가 없습니다. 키는 키 할당에서 정합니다.

### 데코

데코는 장식 그림을 브러시 팁으로 쓰는 브러시입니다. 기본 제공 데코에는 `별`, `반짝 십자`, `점 고리`, `잎 가지`, `꽃잎`, `색종이` 등이 있습니다. 일반 브러시처럼 누르고 끌어서 씁니다.

### 스탬프

- **등록**: 2D 캔버스 창 `⋯` 메뉴의 `스탬프로 등록…`에서 이름을 정하고 등록합니다. 빈 그림은 등록되지 않습니다.
- **목록**: `스탬프` 창이 도구와 함께 열립니다. 맨 위에 개수와 한도(예: 12 / 60, 한도는 60)가 나옵니다. 가득 차면 `스탬프가 가득 찼습니다` 안내가 나옵니다. 행을 누르면 고르고, `지우기`는 확인을 묻습니다.
- **속성**: `스탬프 고르기`, `그리기 색으로 칠하기`(기본 켜짐), `미리보기 표시`(기본 켜짐). 미리보기는 포인터 위의 반투명 그림과 진행 방향 다음 자리의 그림입니다.

![스탬프 창](/img/captures/stamp-window.png)

![스탬프 창이 가득 찬 상태](/img/captures/stamp-window-full.png)

### 무늬

- **기본 제공 8종**: 물방울, 엇갈린 물방울, 줄무늬, 체크, 깅엄 체크, 하운즈투스, 아가일, 가는 격자.
- **내 무늬**: 사용자 무늬가 있을 때만 보입니다.
- **속성**: `무늬 고르기`, `무늬 크기`(기본 64 픽셀), `강도`(기본 최대), `적용 방식`(곱하기가 기본, 빼기, 높이), `명암 반전`(기본 끔).
