# 채우기·그라데이션·도형

**이 문서를 읽으면** 영역을 한 번에 채우고, 색 정지점으로 그라데이션을 만들고, 직선과 도형을 그릴 수 있습니다.

## 채우기

채우기 도구(`G`)에는 서브툴이 다섯 개 있습니다.

| 서브툴 | 하는 일 |
|---|---|
| 섬 채우기 | 누른 곳의 UV 섬을 채웁니다 |
| 레이어 전체 | 레이어 전체를 채웁니다 |
| 재질 전체 | 재질이 쓰는 UV 영역 전체를 채웁니다 |
| 둘러싼 곳 | 선으로 둘러싸인 영역을 채웁니다 |
| 다각형 채우기 | 점을 눌러 만든 다각형 안을 채웁니다 |

섬 채우기와 레이어 전체는 밀도와 투명 픽셀 잠금을 반영하고, 되돌리기 한 단계입니다.

속성 구역 `채우기`에는 허용 오차, 틈 닫기, 영역 확장, 안티앨리어싱, 섬 안쪽만, 참조 대상이 있습니다. 자동 선택과 같은 이름의 속성입니다. → [선택](/guides/selection)

![채우기 서브툴과 속성](/img/captures/fill-subtools.png)

## 그라데이션

그라데이션 도구는 기본 키가 없습니다. 도구를 고르면 그라데이션 창이 함께 열립니다. 창을 닫으면 도구를 다시 고를 때까지 닫힌 채로 있습니다.

### 그라데이션 창

위에서 아래로 블록이 이어집니다.

| 블록 | 하는 일 |
|---|---|
| 프리셋 | 검색창과 `저장`. 목록은 최대 5행이 보이고 안에서 스크롤합니다. 행을 누르면 적용하고, 행 끝의 휴지통은 삭제합니다. 기본 제공 프리셋은 삭제할 수 없습니다 |
| 정지점 띠 | 색 정지점을 추가, 이동, 삭제합니다. 조정 레이어의 그레이디언트 맵과 같은 편집기입니다 |
| 균등 / 뒤집기 / 그리기 색 / 지우기 | 정지점을 같은 간격으로 늘어놓기 / 좌우 뒤집기 / 고른 정지점을 그리는 색으로 바꾸기(`Alt`는 배경색) / 고른 정지점 삭제(2개는 남습니다) |
| 퍼지는 거리 | 원형일 때만 나옵니다. `모델 높이 %`와 `월드 단위`를 바꿔 씁니다 |
| 전체 불투명도 | 그라데이션 전체의 불투명도입니다 |
| 중심 위치 | 3D 공간일 때만 나옵니다. X, Y, Z 값과 `지정`, `지우기` |
| 확정 안내 | 미리보기 중에만 `Enter 확정 · Esc 취소`가 나옵니다 |

- 정지점 `지우기`는 선택된 정지점이 있고 3개 이상일 때만 눌립니다. `균등`과 `뒤집기`는 2개 이상일 때 눌립니다.
- 프리셋 저장은 이름을 묻는 창을 엽니다.
- 중심 `지정`을 누른 뒤 Scene 뷰를 누르면 그 곳이 중심이 됩니다. `지우기`는 중심을 모델 영역의 가운데로 되돌립니다.
- 우클릭 메뉴는 없습니다. 저장과 삭제는 버튼으로 합니다.

![그라데이션 창](/img/captures/gradient-window.png)

### 그라데이션 속성

도구 속성의 `그라데이션` 구역입니다.

| 속성 | 선택지 |
|---|---|
| 그라데이션 모양 | 선형, 원형, 각도, 대칭, 다이아몬드 |
| 범위 밖 | 끝색 유지, 반복, 거울 반복 |
| 뒷면에도 적용 | 켜면 모델 뒷면에도 칠합니다 |
| 적용 공간 | 표면, 3D 공간 |

![원형 그라데이션의 퍼지는 거리](/img/captures/gradient-radial-spread.png)

### 모델 위에서 손잡이로 고치기

3D 공간 그라데이션은 Scene 뷰에 손잡이가 나옵니다. 중심은 브랜드 색, 바깥은 흰색, 정지점은 정지점 색입니다. 손잡이를 끌어 그라데이션이 시작하고 끝나는 위치를 옮깁니다. 원형에서 바깥 손잡이를 끌면 퍼지는 거리 수치가 함께 바뀝니다. 창 위에서는 손잡이가 잡히지 않습니다. UV 캔버스에서는 표면 그라데이션이 확정을 기다리는 동안 중심에서 끝까지 선분과 손잡이 두 개가 나옵니다.

![3D 그라데이션 손잡이](/img/captures/gradient-3d-handles.png)

### 칠하기와 확정

그라데이션을 끌어 미리보기를 보고 `Enter`로 확정하거나 `Esc`로 취소합니다. 화면에는 `Enter 확정 · Esc 취소` 상태 칩이 보입니다.

마스크와 퀵 마스크 면에서 확정하면 그라데이션이 면의 값으로 들어갑니다. 색은 밝기(0.299 R + 0.587 G + 0.114 B)로 바뀌어 칠해집니다. 되돌리기는 한 단계입니다. 덮을 곳이 없으면 `채울 곳이 없습니다` 메시지만 나옵니다.

![그라데이션 확정 칩과 결과](/img/captures/gradient-commit.png)

### 3D에서 본 따라가기

3D 공간의 그라데이션은 본(뼈)을 따라갈 수 있습니다. 본 경로를 고르면 현재 선분 위치가 그 본 기준으로 저장되고, 포즈가 바뀌면 선분이 본을 따라 움직입니다. 씬에서 본을 찾지 못하면 그라데이션은 월드 위치에 남고 `본을 씬에서 찾지 못해 그라데이션을 월드 위치에 둡니다` 메시지가 나옵니다.

- 평면 UV 그라데이션에서는 본 기능이 없습니다.
- 본이 씬에서 사라졌다가 다시 나타나면 그 사이 움직인 위치는 버려지고, 예전 본 기준 오프셋으로 선분이 옮겨집니다. 알려진 한계입니다.

## 도형

도형 도구(`U`)에는 서브툴이 여섯 개 있습니다.

| 서브툴 | 모양 |
|---|---|
| 직선 | 두 점 사이의 직선 |
| 사각형 | 사각형 |
| 타원 | 타원 |
| 다각형 | 변이 여러 개인 다각형 |
| 곡선 | 2차 곡선 |
| 점 곡선 | 점을 지나는 곡선 |

속성은 `도형 종류`, `채우기`, `정비율`, `중심에서`, `변 수`입니다. 확정을 기다리는 도형이 있으면 `Enter 확정 · Esc 취소`가 상태 칩으로 보입니다.
