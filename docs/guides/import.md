# 가져오기

**이 문서를 읽으면** 브러시, 팔레트, 이미지 파일을 MingPainter로 가져오고, 옮기지 못한 설정이 무엇인지 알 수 있습니다.

## 지원 형식

| 형식 | 무엇을 가져오나 | 상태 |
|---|---|---|
| `.abr` (Photoshop 브러시) | 프리셋 하나를 서브툴 하나로 옮깁니다. 옮길 수 없는 설정은 경고로 남깁니다 | 실제 파일의 두 가지 배치(v6.1, v6.2)를 읽습니다 |
| `.sut` (CLIP STUDIO 서브툴) | 팁 연결 정보를 읽습니다 | 가져오기 명령으로 열립니다. 팁은 파일 안의 썸네일 이미지로 만들고, 설정 대응은 추정이라 보고서에 "근사"로 남습니다 |
| `.gpl` (GIMP 팔레트) | 색 목록 | 지원 |
| 이미지 (PNG, JPG 등) | 브러시 팁 이미지 | 지원 |
| `.mpbrush` (MingPainter 브러시) | 이 제품의 브러시 파일 | 지원 |
| WebP | 제외 | 디코더가 없어 지원하지 않습니다 |

## 옮기지 못하는 설정

가져오기는 원본 값을 최대한 옮깁니다. 아래 항목은 옮기지 못하고 경고로 알립니다.

| 원본 설정 | 결과 |
|---|---|
| 기울기 배율 (`tiltScale`) | 옮기지 못합니다 |
| 이중 브러시 (`useDualBrush`) | 옮기지 않고 보존만 합니다 |
| 색 순도 (`purity`) | 옮기지 못합니다 |
| 원형률 조절·최소 (`roundnessDynamics`, `minimumRoundness`) | 지터만 옮깁니다. 조절과 최소는 옮기지 못합니다 |
| 질감 (`useTexture`) | 같은 파일 안의 패턴을 종이 질감으로 옮깁니다. 패턴이 파일에 없으면 옮기지 못합니다 |

## 브러시 라이브러리

가져온 브러시는 브러시 라이브러리에 들어갑니다. 라이브러리는 PC마다 하나이며, 기본 위치는 `%APPDATA%\StudioRaming\MingPainter` 아래입니다. 위치는 설정의 `라이브러리` 탭에서 바꿉니다. `기본 위치로` 행으로 기본 위치에 되돌립니다. → [설정](/reference/settings#라이브러리)
