# PSD

**이 문서를 읽으면** PSD 파일을 레이어째 열고, 작업 결과를 PSD로 내보내고, 어디까지 그대로 옮겨지는지 알 수 있습니다.

## PSD 열기

재질의 텍스처 칸에 `.psd` 파일이 연결되어 있으면, 그 칸을 열 때 PSD가 레이어째 열립니다.

- 레이어, 폴더, 블렌드, 마스크, 조정 레이어가 레이어 패널에 그대로 나옵니다.
- 이미 그 PSD의 `.mpd` 작업 파일이 있으면 PSD 대신 작업 파일을 엽니다.
- 문서 크기는 한 변 4096 픽셀까지입니다. 더 크면 문서가 열리지 않고 상태 줄에 이유가 나옵니다.
- 읽다가 만난 문제는 경고 창에 코드별로 묶여 보입니다. 경고마다 해당 레이어 이름이 붙습니다.

![PSD를 연 직후의 레이어 패널](/img/captures/psd-open-layers.png)

![PSD 경고 창](/img/captures/psd-warnings-window.png)

### 원본 PSD는 바뀌지 않습니다

PSD를 열어 칠해도 PSD 파일은 쓰이지 않습니다. 저장하면 `<이름>_paint.png`와 `.mpd`가 생깁니다. PSD로 다시 내보내려면 아래 `PSD로 내보내기`를 씁니다. PSD로 연 문서는 "원본 레이어" 판정이 꺼집니다.

저장 위치는 [저장과 복구](/guides/save-recover)의 저장 폴더 규칙을 따릅니다.

## PSD로 내보내기

**열기**: 창의 `⋯` 메뉴 또는 레이어 우클릭 메뉴의 `PSD로 내보내기…`. 문서가 열려 있고 내보낼 수 있는 상태일 때만 켜집니다.

내보내기 창에서 옵션 두 개를 고르고 `내보내기`를 누릅니다. 두 옵션 모두 기본으로 켜져 있습니다.

| 옵션 | 뜻 |
|---|---|
| 효과를 픽셀로 굽기 | 레이어 효과를 레이어 픽셀에 합쳐서 씁니다. 끄면 효과는 PSD에 들어가지 않습니다 |
| 색상 균형·선택 색상·색상 바꾸기를 픽셀로 | 이 세 조정은 Photoshop 값으로 정확히 옮길 수 없습니다. 켜면 계산한 결과를 픽셀로 씁니다 |

- 기본 파일 이름은 `<이름>_paint.psd`입니다.
- 내보내기는 문서를 바꾸지 않습니다. 되돌리기 단계가 생기지 않습니다.
- 합성 결과는 저장 PNG와 같은 경로로 만듭니다.
- 굽는 레이어는 불투명도가 픽셀에 구워지고 100%가 됩니다. 블렌드는 유지됩니다.
- 이미 있는 PSD에 덮어쓸 때는 임시 파일에 쓴 뒤 교체합니다. 실패하면 원본이 남습니다.
- 내보내기가 끝났을 때 경고가 있으면 경고 창이 열립니다.

![PSD 내보내기 창](/img/captures/psd-export-window.png)

## 왕복 범위

PSD를 열어서 다시 내보낼 때 항목별로 어디까지 옮겨지는지 정리한 표입니다.

| 항목 | 읽기 | 쓰기 |
|---|---|---|
| 레이어, 폴더, 통과(pass) 폴더 | 지원 | 지원 |
| 블렌드 27종 | 지원 | 지원 |
| 클리핑, 불투명도 | 지원 | 지원 (근사 항목 있음) |
| 칠 불투명도 | 지원 | 지원 (특수 8종은 근사) |
| 마스크 (래스터) | 지원 | 지원 |
| 조정 레이어 | 지원 | 지원 (위 세 조정은 옵션에 따라 픽셀) |
| 레이어 효과 (`lfx2`) | 8종 읽기 | 읽은 효과는 원본 그대로 보존합니다. 이 제품의 효과는 픽셀로 굽거나 생략합니다 |
| 경사·엠보스·새틴 | 원본 보존만 | 원본 보존만 |
| 벡터 마스크, 스마트 오브젝트 | 편집하지 않음 | 편집하지 않음 |
| PSB, 16·32비트, CMYK·Lab | 미지원 | 미지원 |

## 근사 항목

PSD에 옮길 때 값이 조금 다를 수 있는 항목입니다. 내보낼 때 경고로 알립니다.

- 클리핑 레이어를 그룹으로 혼합 (끔이 켬으로 근사됩니다)
- 클리핑 바탕의 칠 불투명도
- 칠 불투명도의 특수 8종

## 한계

- Mono 32비트와 .NET 64비트 사이에서 합성 결과가 최대 1 차이 날 수 있습니다.
- 흰 매트 합성은 알파 128 미만에서 색 오차가 큽니다. Photoshop과 같은 한계입니다.
