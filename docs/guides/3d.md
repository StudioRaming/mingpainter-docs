# 3D 작업

**이 문서를 읽으면** 모델의 일부만 칠하도록 가리고, 좌우 대칭의 중심을 맞추고, 본 가중치로 선택을 만들고, 표면을 따라 흐리고, AO를 굽고, 요철을 노멀 맵에 칠하고, 여러 재질을 세트로 다룰 수 있습니다.

이 문서의 기능은 모두 모델(3D 렌더러)을 기준으로 합니다. 대부분의 창은 도구창 목록에서 엽니다.

## 표시 범위 (숨김)

숨김은 **면(삼각형) 단위**로 칠할 수 있는 곳을 가립니다. 메쉬는 바뀌지 않습니다. 칠하기, 선택, 깊이 계산에서만 숨긴 면을 뺍니다.

- 숨긴 면에는 칠해지지 않습니다. 숨긴 면은 뒤쪽 면을 가리지 않습니다.
- **면 숨김**, **섬 숨김**, **오브젝트 숨김**은 따로 저장됩니다. 셋 중 하나라도 숨긴 면은 보이지 않습니다.
- 숨김은 UV 캔버스에도 적용됩니다. UV 획, 평면 그라데이션, UV 모양 선택이 숨긴 자리를 건너뜁니다.

### 키와 명령

키 세 개는 [단축키](/reference/shortcuts) 표에 있습니다.

| 명령 | 키 | 하는 일 |
|---|---|---|
| 선택 숨기기 | `H` | 선택 영역의 면을 숨기고 선택을 해제합니다. `Ctrl+Shift+D`로 선택을 되돌립니다. 선택이 없으면 아무것도 바꾸지 않고 상태 줄에 알립니다 |
| 선택한 곳만 표시 | `Shift+H` | 선택 영역 밖의 면을 모두 숨깁니다. 선택은 그대로 남습니다 |
| 전부 표시 | `Alt+H` | 면, 섬, 오브젝트 숨김을 모두 풉니다 |

같은 명령은 창 메뉴의 `표시 범위` 아래에도 있습니다. 이 메뉴에는 `이 섬 숨기기`, `이 섬만 표시`, `반전`, `확장`, `축소`, `창 열기`가 함께 나옵니다.

### 표시 범위 창

| 화면 문구 | 하는 일 |
|---|---|
| 선택한 곳만 표시 | 선택 영역 밖의 면을 숨깁니다 |
| 선택 숨기기 | 선택 영역을 숨기고 선택을 풉니다 |
| 전부 표시 | 면, 섬, 오브젝트 숨김을 모두 풉니다 |
| 이 섬 숨기기 / 이 섬만 표시 | 누른 UV 섬을 숨기거나 그 섬만 보이게 합니다. Scene 뷰에서 우클릭한 곳의 섬에 같은 이름의 항목이 나옵니다 |
| 반전 | 면 숨김을 뒤집습니다 |
| 확장, 축소 | 숨긴 면 집합을 면 인접 기준으로 한 겹씩 넓히거나 줄입니다 |

창 위의 상태 줄에는 숨김 상태가 한 줄로 나옵니다.

- 숨김이 없으면 `숨김 없음`
- 숨김이 있으면 `숨김 {0}%` 형식으로 숨긴 비율이 나옵니다
- 프리셋을 불러온 뒤에는 `프리셋: {0}`(프리셋 이름), 반전 중이면 `반전됨`

### 오브젝트 눈

오브젝트 목록은 표면의 렌더러마다 한 줄씩 보입니다. 눈 아이콘을 누르면 그 오브젝트의 보임이 바뀝니다. **Alt+클릭**은 `이것만` 보이기입니다. 오브젝트 숨김은 계층 경로로 저장됩니다.

### 숨김 프리셋

- `현재 숨김 저장`으로 지금의 숨김 상태를 이름과 함께 저장합니다. 빈 이름은 저장되지 않습니다. 프리셋은 문서 파일(`.mpd`)에 들어갑니다.
- 목록에서 `불러오기`, `이름 바꾸기`, `지우기`를 합니다. 프리셋이 없으면 `저장된 프리셋이 없습니다`가 나옵니다.
- 프리셋은 **면 수와 섬 수가 같은 메쉬에서만** 불러옵니다. 다르면 아무것도 바뀌지 않고 상태 줄에 알립니다.

### 숨김을 쓸 때 알아 둘 점

- 칠하기 도중에는 숨김을 바꾸지 않습니다. 획과 획 사이에만 바꿉니다.
- 어떤 면도 덮지 않는 자리(거터)는 보이는 쪽으로 취급합니다. 숨긴 섬 가장자리 바깥이 칠해질 수 있습니다.

## 대칭 고급

대칭 고급 창은 [칠하기](/guides/painting#대칭)의 대칭 X, Y, Z 설정을 더 세밀하게 맞춥니다. 대칭을 켜고 끄는 것은 `대칭/X`, `대칭/Y`, `대칭/Z` 메뉴 또는 `대칭 켜기 (X)` 항목으로 합니다.

| 항목 | 설정 |
|---|---|
| 중심 | `자동`(모델에서 추정), `원점`(Animator 루트의 원점, Animator가 없으면 렌더러의 루트 원점), `직접 지정` |
| 직접 지정 | X, Y, Z 수치를 입력하거나 `Scene에서 점 클릭`으로 표면의 점을 찍습니다. `중심을 가까운 정점으로`를 켜면 가장 가까운 정점에 맞춥니다 |
| 허용 범위 | 0~3 %, 기본 1 %. 모델 바운딩 박스 대각선을 기준으로 한 반경입니다 |
| 레스트 포즈 기준 | 켜면 모델을 가져올 때의 기본 자세 정점을 기준으로 거울 위치를 계산합니다. 그 데이터가 없으면 지금 자세를 씁니다 |
| 반사 획을 정점에 맞추기 | 반사된 획의 위치를 가까운 정점에 맞춥니다. 표면 스냅이 켜져 있을 때만 적용됩니다 |

- 허용 범위는 정점 맞춤이 켜져 있을 때 쓰입니다.
- 비균일 배율(예: 1, 2, 1)을 가진 렌더러는 축에 맞춘 평면에서만 정확합니다.

## 웨이트 선택

웨이트 선택은 고른 본(뼈)의 가중치가 있는 곳을 선택 영역으로 만듭니다. 도구창 목록에서 `웨이트 선택`을 엽니다.

- 본 목록은 트리로 보이며 깊이만큼 들여씁니다. 여러 본을 체크할 수 있습니다.
- `임계`는 기본 50 %입니다. 웨이트 값이 임계를 **넘는** 곳이 선택됩니다.
- `웨이트 강도로`를 켜면 웨이트 값이 선택 강도로 쓰입니다.
- `선택에 합치기`는 `새로 선택`, `더하기`, `빼기`, `교차` 중 하나입니다.
- `이 범위만 표시`는 체크한 본의 가중치 면만 남기고 나머지 면을 숨김 층으로 가립니다. 선택 채널은 바뀌지 않고, 이 변경은 되돌리기 단계가 아닙니다.
- `선택 적용`으로 선택을 확정하고, `모두 해제`로 체크를 지웁니다. 체크한 본이 없으면 `체크한 본이 없습니다`가 나옵니다.
- 메쉬 렌더러가 없거나 웨이트가 없는 모델은 선택이 0입니다.

![웨이트 선택 창](/img/captures/weight-window.png)

## 표면 방향 흐림

표면 방향 흐림은 면을 따라 한 방향으로 색을 번지게 합니다. 필터 메뉴의 `표면 방향 흐림…`에서 시작합니다. 흐림은 활성 레이어에 걸리며, 미리보기 중에는 다른 필터가 열리지 않습니다.

1. **방향**: Scene 뷰의 화살표를 끌어 정합니다. 기본 방향은 -Y입니다.
2. **길이**: cm로 적고, 모델 높이의 %를 함께 보여 줍니다.
3. **양방향**: 켜면 화살표 양쪽으로 번집니다. 끄면 방향 쪽으로만 모입니다.
4. `Enter`는 확정, `Esc`는 취소입니다. 확정은 흐림 한 단계로 되돌립니다. 취소하면 레이어가 원래 픽셀로 돌아갑니다.

- **이음새 넘어 번짐**: UV 이음새로 이어진 면 쌍을 건너 번집니다. 이 쌍은 표면마다 한 번 계산되고, 자세가 바뀌면 흐림에 쓰이는 단계 지도를 다시 만듭니다.
- 표면이 없는 재질에서는 `표면이 없어 표면 방향 흐림을 쓸 수 없습니다`가 나옵니다.

## AO 굽기

AO 굽기는 모델 주변의 가림을 계산해 회색 결과를 만듭니다. 창은 `레이어 > AO/굽기…`에서 엽니다.

| 항목 | 설정 |
|---|---|
| 문서 | 굽을 재질 문서마다 `굽기`와 `그림자 드리우기`를 따로 고릅니다 |
| 품질 | 32, 64, 128 방향 중 하나. 방향이 많을수록 정밀하고 느립니다 |
| 거리 | 3 cm, 8 cm, 20 cm 중 고르거나 수치(cm)를 입력합니다 |
| 모델 높이에 비례 | 켜면 거리에 모델 높이 / 160 cm를 곱합니다 |
| 강도, 대비 | 결과의 세기와 명암 대비를 조절합니다 |
| 알파 인지 | 켜면 투명 재질(예: 머리카락 카드)은 알파가 0.5 이상인 곳만 가립니다 |
| 기울기 bias | 켜면 기울어진 면의 자기 그림자 오염을 줄이는 깊이 여유를 기울기에 맞춥니다 |
| 다른 그림자 무시 | 켜면 다른 오브젝트가 드리우는 그림자를 계산에서 뺍니다 |

- `굽기 시작`을 누르면 진행 줄에 `방향 n / m`이 나옵니다. `취소`를 누르면 상태가 `대기 중`으로 바뀌고 결과는 레이어에 쓰이지 않습니다.
- 모든 문서가 끝나면 결과가 문서마다 **`AO` 레이어**가 됩니다. 레이어는 곱하기 블렌드로 들어가며, 문서마다 되돌리기 한 단계입니다.
- `PNG 내보내기`로 결과를 파일로 저장합니다.

## 요철 (노멀)

요철 도구(`요철(노멀)`)는 칠한 자리를 높이로 보고 노멀 맵을 만듭니다. 도구 띠에서 켜져 있습니다.

### 도장 9종

요철 도구의 서브툴은 아래 9개입니다. 이름은 화면 문구 그대로입니다.

| 번호 | 화면 문구 |
|---|---|
| 1 | 점선 오목 |
| 2 | 볼록 |
| 3 | 홈 |
| 4 | 돌출 |
| 5 | 크로스스티치 |
| 6 | 지그재그 |
| 7 | 리벳 |
| 8 | 주름 |
| 9 | 부풀림 |

### 요철 칸

요철 펜은 지금 칠하고 있는 문서에 높이를 그립니다. 노멀 맵에 요철을 넣으려면 재질의 노멀 문서를 열고 그 문서에 칠합니다. 색 문서에서 요철 도구를 고르면 상태 줄이 알려 줍니다.

- 노멀 문서가 열려 있으면: `요철은 노멀 문서 {재질 이름}에 그립니다. 노멀 문서를 여세요.`
- 노멀 칸은 있는데 노멀 문서가 열려 있지 않으면: `이 재질에 노멀 슬롯이 있습니다. 노멀 문서를 열어 요철 대상으로 지정하세요.`

`요철 칸` 패널에서는 문서마다 요철을 둘 곳을 고릅니다. 고른 값은 문서와 함께 저장됩니다.

- **노멀에 합성**: 재질의 노멀 위에 섞습니다. 기본값입니다.
- **별도 칸**: 재질의 다른 텍스처 칸에 따로 둡니다.

:::note[베타에서는 선택만 저장됩니다]
0.1.0-beta.1에서는 이 선택이 요철 펜이 칠하는 문서를 바꾸지 않습니다. 요철은 노멀 문서를 열어 그 문서에 칠하세요.
:::

재질에 노멀 칸은 있는데 노멀 텍스처가 비어 있으면, `노멀에 합성`을 누를 때 `노멀맵이 없습니다. 새 노멀 문서를 만들까요?`를 묻습니다. `만들기`를 누르면 평평한 노멀 문서를 만들어 엽니다. `취소`를 누르면 아무것도 바꾸지 않고, 그 문서에서는 다시 묻지 않습니다. 그 뒤에 `노멀에 합성`을 누르거나 재질에 노멀 칸이 없으면 상태 줄에 `노멀 문서가 없어 기존 노멀을 대상으로 할 수 없습니다.`가 나옵니다.

### 높이를 노멀로 필터

필터 메뉴의 `높이를 노멀로`는 칠한 높이를 노멀 맵으로 바꾸는 필터입니다. `요철 세기`로 기울기를 정합니다. 다른 필터와 같이 미리보기와 `Enter` 확정을 씁니다.

## 메쉬 다시 임포트

모델 파일을 다시 임포트하면 문서가 자동으로 메쉬를 다시 읽습니다. 상태 줄에 아래 내용이 나올 수 있습니다.

| 상황 | 결과 |
|---|---|
| UV가 바뀜 | 섬을 다시 계산합니다. 선택과 숨김 프리셋은 무효가 됩니다 |
| 삼각형 수가 바뀜 | 숨김을 풀어 전부 보이게 합니다 |
| 메쉬를 읽지 못함 | `다시 임포트한 메쉬를 읽지 못했습니다: {이유}`를 알립니다 |

재질이 프로젝트에서 사라진 세트는 [세트](#세트와-세트-메모리)에서 `재질 없음`으로 보입니다.

## MaskMaker 연동

MaskMaker가 만든 마스크 PNG를 선택 영역으로 씁니다.

1. 선택 도구 메뉴의 `MaskMaker 마스크에서…`를 고릅니다.
2. `MaskMaker 마스크` 창에서 `파일 고르기…`로 PNG를 고릅니다.
3. 채널(R, G, B, A) 중 하나를 고릅니다.
4. `선택에 적용`으로 선택에 더하거나 새로 선택합니다.

- MaskMaker가 설치되어 있지 않으면 `MaskMaker가 설치되어 있지 않습니다`가 나옵니다.
- MaskMaker에서 연 세션이 남아 있으면 `MaskMaker 세션 사용 중`이 나옵니다. MaskMaker가 저장하지 않은 칠을 가지고 있으면 MingPainter는 Scene 입력을 넘겨받지 않고 상태 줄에 이유를 알립니다.
- `MM 생성기 결과 불러오기`는 맷캡, 캐비티 같은 MaskMaker 출력 PNG를 새 레이어로 가져옵니다.

## 세트와 세트 메모리

한 모델에 재질이 여러 개면 재질마다 문서가 열립니다. 이 문서들을 **세트**라고 부릅니다.

### 자동 전환

`자동 전환`(Scene 뷰의 세트 줄)을 켜면, 다른 재질 위에서 획을 시작할 때 그 재질의 세트로 바로 바뀝니다. 열려 있지 않은 세트는 열면서 `열리는 중: {이름}`을 보여 줍니다. 선택 영역이 있으면 다른 재질로 넘어가지 않습니다. 선택을 풀면 넘어갑니다.

### 세트 메모리

`세트 메모리` 창은 열린 문서마다 GPU 메모리 사용량을 보여 줍니다.

- 쓰는 중인 세트는 `GPU {0}`(바이트)로 나옵니다.
- 잠든 세트는 `잠듦`으로 나옵니다.
- 맨 아래 `GPU 합계`는 세트별 값의 합입니다.

잠재우기 규칙은 아래와 같습니다.

- 활성 세트와 그 직전 세트는 깨어 있습니다.
- 나머지 세트는 **30초** 동안 쓰지 않으면 잠듭니다. 잠들면 GPU 객체를 내리고 픽셀을 잠재우기 저장소로 옮깁니다.
- 열린 문서의 GPU 추정치가 장치 메모리의 **70%**를 넘으면 `GPU 메모리 주의`, **90%**를 넘으면 `GPU 메모리 위험`을 알립니다.

### 재질 없는 세트와 레이어 옮기기

재질이 프로젝트에서 사라진 세트는 `재질 없음: {이름}`으로 표시됩니다. `레이어 옮기기…`를 누르면 그 세트의 최상위 레이어(폴더는 하위 전체)를 **다른 열린 세트로 옮깁니다**.

- `옮길 레이어`와 `대상 세트`를 고르고 `옮기기`를 누릅니다. 대상 세트 맨 위에 원래 순서로 들어가며, 대상 세트의 되돌리기 한 단계입니다.
- 대상이 채널 문서이거나 채널 폴더이면 거부합니다.
- 두 세트 중 하나가 칠하는 중이면 `레이어 옮기기`를 시작하지 않습니다.
