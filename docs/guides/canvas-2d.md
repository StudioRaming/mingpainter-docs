# 2D 캔버스

**이 문서를 읽으면** 3D 모델 없이 빈 캔버스에 그림을 그리고, 그 그림을 스탬프로 등록하거나 모델과 재질에 붙일 수 있습니다.

3D 모델 없이 빈 캔버스에 그림을 그립니다. 칠하는 도구는 UV 캔버스와 같습니다.

## 새로 만들기

창의 `⋯` 메뉴에서 `2D 캔버스 새로 만들기…`를 고릅니다.

- **크기**: 긴 변이 256, 512, 1024, 2048 중 하나입니다. 모양은 정사각, 가로형, 세로형입니다. 가로형과 세로형은 4:3 비율이며, 짧은 변은 긴 변의 3/4(64의 배수)입니다. 열두 가지 중에서 고릅니다.
- 기본값은 1024×1024 정사각형입니다. 마지막에 고른 크기와 모양을 기억합니다.
- 선택한 크기는 폭과 높이(px), 그리고 비율로 보입니다.
- **저장 위치**: 비워 두면 `Assets/MingPainter/Canvas/` 아래에 `Canvas_가로x세로.mpd`로 만듭니다. 같은 이름이 있으면 번호를 붙입니다. `찾아보기`로 다른 곳을 고를 수 있습니다.
- `Enter`는 만들기, `Esc`는 닫기입니다.

![2D 캔버스 새로 만들기 창](/img/captures/canvas2d-new-dialog.png)

## 캔버스 창

새 캔버스는 자기 창에서 열립니다.

- 제목 줄에 이름, 저장하지 않은 변경 표시, 크기, `좌우 대칭` 토글, `⋯` 메뉴가 있습니다.
- `좌우 대칭`을 켜면 그림을 좌우 대칭으로 그립니다.
- `⋯` 메뉴에는 도구창 목록, `PNG로 저장…`, `캔버스 닫기`가 있습니다.
- 저장하지 않은 변경이 있으면 닫을 때 `저장하고 닫기`, `저장 안 함`, 취소를 묻습니다.
- 다른 문서가 활성일 때는 캔버스 창에 칠하지 않고 `눌러서 이 캔버스로 돌아옵니다` 버튼만 나옵니다. 엉뚱한 문서에 칠하지 않게 하려는 것입니다.
- 메인 창 `⋯` 메뉴의 `열린 2D 캔버스` 하위 목록에서 열린 캔버스로 이동합니다.
- 캔버스는 `.mpd` 파일로 저장됩니다. PNG는 `PNG로 저장…`으로 따로 내보냅니다.

## 출력

2D 캔버스 창의 `⋯` 메뉴 `내보내기`에서 할 수 있는 일입니다.

| 항목 | 하는 일 |
|---|---|
| `스탬프로 등록…` | 이름을 묻고 스탬프 목록에 넣습니다. `투명한 여백 자르기`는 기본으로 켜져 있습니다. 그림이 비어 있으면 등록하지 않습니다. 목록은 60개까지입니다 |
| `3D에 붙이기` | 이 캔버스의 그림을 화면 기준으로 모델에 붙입니다. 변형의 화면 투영과 같은 방식입니다. Scene 뷰를 찾지 못하면 상태 줄에 알립니다 |
| `UV 텍스처에 붙이기` | 열려 있는 재질 문서에 붙입니다 |
| `밑그림 놓기…`, `밑그림 치우기`, `밑그림 진하기` | 참고 그림을 캔버스 아래에 흐리게 깝니다. 진하기는 25, 50, 75, 100% 중에서 고릅니다. 밑그림은 저장과 PNG 출력에 들어가지 않습니다 |
