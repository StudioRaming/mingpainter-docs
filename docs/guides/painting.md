# 칠하기

**이 문서를 읽으면** 도구 띠의 도구와 서브툴을 고르고, 혼색과 이중 끝을 쓰고, 대칭과 UV 이음새 설정을 맞출 수 있습니다.

칠하기 도구는 **도구 띠**에 모여 있습니다. 도구를 고르면 그 도구의 서브툴과 속성이 브러시 도구창에 나옵니다.

## 도구 띠

| 도구 | 기본 키 (CSP) | 기본 키 (PS) | 하는 일 |
|---|---|---|---|
| 펜 | `P` | `P` | 선이 날카로운 그림을 그립니다 |
| 붓 | `B` | `B` | 질감과 번짐이 있는 그림을 그립니다 |
| 에어브러시 | 기본 키 없음 (키 할당 가능) | 기본 키 없음 (키 할당 가능) | 뿌리듯 칠합니다 |
| 브러시 모음 | 기본 키 없음 (키 할당 가능) | 기본 키 없음 (키 할당 가능) | 연필, 목탄, 스펀지 등 여러 질감의 브러시를 모아 둡니다 |
| 지우개 | `E` | `E` | 칠한 픽셀을 지웁니다 |
| 채우기 | `G` | `G` | 영역을 색이나 재질 전체로 채웁니다 |
| 스포이트 | `I`, `Alt`를 누르는 동안 | `I`, `Alt`를 누르는 동안 | 화면의 색을 가져옵니다 |
| 혼색 (흐리기·손끝·색 섞기) | `J` | `R` | 이미 칠한 색을 번지게 하거나 끌고 갑니다 |
| 그라데이션 | 기본 키 없음 (키 할당 가능) | 기본 키 없음 (키 할당 가능) | 색이 점점 바뀌는 면을 만듭니다 |
| 도형 | `U` | `U` | 직선, 사각형, 타원, 곡선을 그립니다 |
| 선택 | `M` | `M` | 칠할 곳을 제한하는 영역을 고릅니다 |
| 자동 선택 (마법봉) | `W` | `W` | 비슷한 색의 영역을 한 번에 고릅니다 |
| 이동·변형 | `V`, `Ctrl+T` | `V`, `Ctrl+T` | 선택한 그림을 옮기고 늘리고 돌립니다 |
| 텍스트 | `T` | `T` | 글자를 레이어로 씁니다 |
| 자 | 기본 키 없음 (자 전환은 `Ctrl+Alt+R`) | 기본 키 없음 (자 전환은 `Ctrl+Alt+R`) | 선이 따라갈 가이드를 만듭니다 |
| 데코·스탬프·무늬 | 기본 키 없음 (키 할당 가능) | 기본 키 없음 (키 할당 가능) | 장식 그림, 등록한 그림, 반복 무늬를 찍습니다 |

:::note[키는 설정에서 바꿀 수 있습니다]
기본 키는 [단축키](/reference/shortcuts) 표에서 확인합니다. 설정 창의 `키 할당`에서 바꿀 수 있습니다. → [설정](/reference/settings)
:::

아직 쓸 수 없는 도구는 도구 띠에서 흐리게 보입니다.

## 서브툴

**서브툴**은 도구 안의 브러시 한 종류입니다. 도구마다 서브툴 목록이 다릅니다. 전체 목록은 [서브툴](/reference/subtools)에 있습니다.

예를 들어 펜 도구에는 `G펜`, `둥근 펜`, `밀리펜`, `입·출 테이퍼 펜`, `솔리드 펜`이 있습니다.

## 혼색 도구

혼색 도구에는 서브툴이 세 개 있습니다. 이미 칠해 둔 색을 섞어 자연스럽게 번지게 할 때 씁니다.

| 서브툴 | 하는 일 |
|---|---|
| 흐리기 | 붓이 지나가는 곳의 색을 흐립니다 |
| 문지르기 | 붓이 지나가는 곳의 색을 끌고 갑니다 |
| 색 섞기 | 붓에 색을 묻혀 칠합니다. 붓이 아래 색을 집어 칠하는 색과 섞습니다 |

혼색 도구의 속성은 `섞기` 구역에 있습니다.

| 속성 구역 | 속성 | 뜻 |
|---|---|---|
| 섞기 | 섞는 방식 | 흐리기, 문지르기, 색 섞기 |
| 섞기 | 흐림 범위 | 흐리기에서 얼마나 멀리까지 섞을지 (텍셀 단위, 최대 32) |
| 섞기 | 세기 | 문지르기가 얼마나 끌고 가는지 |
| 섞기 | 집색 반경 | 색 섞기가 색을 집는 범위 |
| 색 섞기 | 물감 양 | 집은 색을 칠하는 색에 섞는 정도 |
| 색 섞기 | 번짐 | 획이 길어져도 집은 색이 얼마나 오래 남는지 |
| 색 섞기 | 혼색 방식 | 전체 설정, 물감, 디지털 |
| 색 섞기 | 모든 레이어에서 집색 | 켜면 보이는 합성 색에서 집습니다. 끄면 칠하는 레이어에서 집습니다 |

- `물감` 방식은 물감처럼 색이 섞입니다. 노랑과 파랑을 섞으면 초록 쪽으로 갑니다. `디지털` 방식은 색 값을 그대로 평균합니다. `전체 설정`은 색 도구창의 혼합 탭 선택을 따릅니다.
- 흐리기와 문지르기는 획을 긋는 동안 끝 부분의 임시 미리보기를 그리지 않습니다. 마지막 도장은 획을 놓을 때 확정됩니다.
- 문지르기는 UV 텍셀 평면에서 끌립니다. Scene 뷰에서 붓이 여러 UV 섬에 걸치면 붓 중심이 있는 섬 쪽만 끌립니다.
- 선택 영역이 있으면 흐리기, 문지르기, 색 섞기 모두 선택 안에서만 바뀝니다.

## 이중 끝 (듀얼 팁)

브러시 속성의 `이중 끝` 구역에서 둘째 팁을 켭니다. 둘째 팁이 첫 팁과 겹쳐 획의 모양을 만듭니다. 거친 질감이나 흩어지는 획에 씁니다.

| 속성 | 뜻 |
|---|---|
| 이중 끝 사용 | 켜면 둘째 팁이 쓰입니다 |
| 크기 비율 | 첫 팁 대비 둘째 팁 크기 (0.05~2배) |
| 간격 | 둘째 팁이 떨어지는 간격 |
| 흩뿌리기 | 둘째 팁 위치가 흩어지는 정도 |
| 합치는 방식 | 곱하기, 어둡게, 밝게, 오버레이, 선형 높이, 하드 믹스 |

- 합치는 방식은 알파를 기준으로 해석합니다. Photoshop의 이중 브러시와 모양이 다를 수 있습니다.
- 둘째 팁 이미지는 하나만 씁니다.
- UV 이음새를 넘어 칠하는 획에서는 이중 끝이 적용되지 않습니다.

![이중 끝 속성과 획](/img/captures/dualtip-properties.png)

## 브러시 속성

도구를 고르면 브러시 도구창에 서브툴의 속성이 나옵니다. 도구창 위의 `주요`와 `전체` 탭으로 자주 쓰는 속성만 보거나 전부 봅니다. 속성은 구역으로 묶입니다.

| 구역 | 들어 있는 것 |
|---|---|
| 브러시 끝 | 끝 모양, 경도, 이미지 팁 |
| 크기와 동적 | 크기, 펜 압력 등으로 변하는 크기 |
| 불투명도와 흐름 | 불투명도, 흐름과 그 동적 설정 |
| 간격과 흩뿌림 | 간격, 흩뿌림 |
| 각도 | 끝 각도, 각도 흔들림 |
| 용지 질감 | 종이 질감 |
| 입·출 | 시작과 끝의 가늘어짐(테이퍼) |
| 보정 | 손떨림 보정 강도 |
| 누적 | 덧칠 방식 |
| 합성 | 합성 관련 설정 |
| 색 흔들림 | 색 흔들림 |
| 3D 기본값 | Scene 뷰에서 칠할 때의 기본값 |
| 섞기 / 색 섞기 / 이중 끝 | 혼색 도구와 이중 끝 |
| 선택 / 채우기 / 도형 / 그라데이션 | 해당 도구 |

브러시 속성은 서브툴마다 따로 저장됩니다. 같은 서브툴을 고쳐 쓰다가 `초기화`를 누르면 기본값으로 돌아갑니다.

브러시 막대의 크기 슬라이더는 사각형, 타원, 올가미, 다각형, UV 섬, 면, 자동 선택에서는 나타나지 않습니다. 이 모양들은 크기를 쓰지 않기 때문입니다. 선택 브러시와 선택 지우개는 크기를 씁니다.

![브러시 속성 창](/img/captures/paint-brush-properties.png)

## 펜 압력

펜 입력은 Windows의 WinTab 경로와 Unity 펜 이벤트 경로를 씁니다. 펜이 감지되지 않으면 [문제 해결](/troubleshooting#펜이-감지되지-않는다)을 봅니다.

필압이 크기와 불투명도에 주는 영향은 서브툴마다 다릅니다. `크기와 동적`과 `불투명도와 흐름` 구역에서 정합니다. 펜 자체의 압력 보정은 설정 창의 `펜·입력` 탭에서 합니다. → [설정](/reference/settings)

![설정 창의 펜 보정 패드](/img/captures/settings-pen-pad.png)

## 손떨림 보정

브러시 속성의 `보정` 구역에서 강도를 정합니다. 서브툴마다 따로 저장됩니다. 예를 들어 `입·출 테이퍼 펜`의 기본 보정 강도는 0.2입니다.

## 대칭

브러시 막대의 `대칭` 메뉴에서 X, Y, Z 축 대칭을 켭니다. 한쪽을 칠하면 반대쪽에도 같이 칠해집니다. 대칭 중심과 축은 모델에서 추정합니다. 칠하는 커서에 대칭 링이 함께 보입니다. 대칭 설정은 도메인 리로드 뒤에도 유지됩니다.

![대칭 메뉴와 대칭 링](/img/captures/paint-symmetry.png)

## 뒷면까지 칠하기

브러시 속성의 `뒷면·가려진 면도 칠하기`를 켜면 카메라에서 가려진 면과 뒷면까지 칠합니다. 끄면 보이는 면만 칠합니다.

## UV 이음새 넘어 칠하기

UV 캔버스에서 칠할 때 획이 UV 섬의 경계를 넘어 이웃한 면으로 이어집니다. 모델 위에서 이어져 있는 두 섬에 걸쳐 한 번에 칠할 수 있습니다.

- 기본으로 켜져 있습니다. UV 캔버스의 `이어 칠하기` 토글로 켜고 끕니다.
- 모델 표면 정보가 있을 때만 동작합니다.
- 120도 넘게 크게 꺾인 면으로는 넘어가지 않습니다.
