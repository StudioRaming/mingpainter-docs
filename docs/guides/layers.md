# 레이어

**이 문서를 읽으면** 레이어에 블렌드 모드와 마스크를 붙이고, 조정 레이어와 효과로 색을 바꾸고, 필터와 자동 레이어 나누기를 쓸 수 있습니다.

레이어 패널은 래스터 레이어, 폴더, 조정 레이어를 한 목록으로 보여 줍니다.

## 블렌드 모드

레이어와 폴더는 블렌드 모드 29종을 씁니다. Photoshop의 27종과 CSP의 2종(`광채 닷지`, `더하기(발광)`)입니다. 블렌드 목록은 7묶음으로 나뉘고, 묶음 사이에 구분선이 있습니다.

속성 줄에서 블렌드를 고릅니다. 그 아래 줄에 `칠` 슬라이더가 있습니다.

![블렌드 드롭다운을 펼친 레이어 패널](/img/captures/layers-panel-blend.png)

## 레이어 마스크

**마스크**는 레이어에서 보일 곳과 숨길 곳을 정하는 회색 이미지입니다. **흰색은 보이고, 검정은 숨습니다.**

### 만들기

레이어를 우클릭하거나 레이어 카드의 마스크 버튼을 눌러 고릅니다.

| 메뉴 | 결과 |
|---|---|
| 마스크 추가: 전부 보이게(흰색) | 흰색 마스크 |
| 마스크 추가: 선택 영역에서 | 지금 선택 영역이 마스크가 됩니다 |
| 마스크 추가: 전부 숨기기(검정) | 검정 마스크. 레이어가 모두 숨습니다 |

다음 경우에는 마스크를 만들 수 없습니다. 메뉴가 흐려지고 이유가 괄호로 붙습니다.

- 레이어를 고르지 않았습니다.
- 채널 폴더입니다.
- 잠긴 레이어입니다.
- 밑바탕(원본) 레이어입니다.
- 이미 마스크가 있습니다.

### 마스크 칠하기

레이어 행에는 색 썸네일, 연결 아이콘, 마스크 썸네일이 차례로 있습니다.

| 조작 | 하는 일 |
|---|---|
| 마스크 썸네일 클릭 | 마스크에 칠합니다. 썸네일에 테두리가 생깁니다 |
| 색 썸네일 클릭 | 색 칠하기로 돌아옵니다 |
| Shift + 마스크 썸네일 | 마스크를 켜고 끕니다. 꺼지면 빨간 X가 보입니다 |
| Ctrl + 마스크 썸네일 | 마스크를 선택 영역으로 만듭니다 |
| Ctrl + 색 썸네일 | 레이어 모양을 선택 영역으로 만듭니다 |
| 연결 아이콘 | 마스크가 레이어를 따라 움직일지 정합니다 |

Ctrl 조작에 Shift를 더하면 더하기, Alt를 더하면 빼기, Shift와 Alt를 함께 누르면 교집합입니다.

마스크에 검정으로 칠하면 칠한 곳이 사라지고, 흰색으로 칠하면 돌아옵니다. 마스크를 칠하는 동안 스포이트는 마스크 값이 아니라 합성된 색을 집습니다. 다른 레이어를 고르면 자동으로 색 칠하기로 돌아옵니다.

레이어 지우기(`Del`)는 칠하고 있는 면을 따릅니다. 마스크 면에서는 마스크를 흰색으로 채웁니다.

### 적용과 삭제

- **마스크 적용**: 마스크를 레이어 픽셀에 합치고 마스크를 없앱니다. 일반(래스터) 레이어에서만 됩니다.
- **마스크 삭제**: 마스크만 없앱니다. 레이어는 그대로입니다.

두 동작 모두 되돌리기 한 단계입니다.

![마스크 썸네일이 있는 레이어 행](/img/captures/layers-mask-rows.png)

![마스크로 칠한 모델 결과](/img/captures/layers-mask-paint-result.png)

## 퀵 마스크

`Q` 키로 켜고 끕니다. 도구 띠 맨 아래의 토글로도 켭니다. 켜면 선택 밖이 빨간 반투명으로 덮이고, 그 위에 칠해서 선택 영역을 고칩니다. 끄면 칠한 모양이 선택 영역이 됩니다.

- 칠하는 동안 Scene 상태 줄에 `퀵 마스크`가 보입니다.
- 저장한 PNG에는 빨간 덧칠이 들어가지 않습니다.
- 퀵 마스크 중 레이어 지우기(`Del`)는 선택 해제입니다.

![퀵 마스크를 켠 상태](/img/captures/layers-quickmask-on.png)

## 칠 불투명도

`칠` 불투명도는 효과를 뺀 레이어 자체의 불투명도입니다. 효과(그림자 등)는 칠을 낮춰도 그대로 보입니다. 조정 레이어와 채널 폴더에서는 슬라이더가 흐려집니다.

## 조정 레이어

조정 레이어는 아래에 있는 레이어들의 색을 바꿉니다. 픽셀은 건드리지 않습니다.

| 조정 | 비고 |
|---|---|
| 색조/채도 | |
| 명도/대비 | |
| 레벨 | 채널 선택, 핸들 5개, 히스토그램 |
| 반전 | 값이 없습니다. 안내 줄만 나옵니다 |
| 흑백 | |
| 포스터화 | |
| 한계값 | |
| 그레이디언트 맵 | 정지점 추가·이동·색·삭제 |
| 톤 커브 | 점 추가·끌기·더블클릭으로 삭제, 히스토그램 |
| 색상 균형 | PSD 내보내기에서 근사 |
| 선택 색상 | PSD 내보내기에서 근사 |
| 색상 바꾸기 | PSD 내보내기에서 근사 |

**만들기**: 레이어 카드의 조정 레이어 버튼을 누르고 종류를 고릅니다. 현재 레이어 위, 같은 폴더에 생깁니다.

**값을 고칠 때**: 조정 행의 썸네일을 누르면 조정 창이 열립니다. 도구창 메뉴에서도 켭니다.

- 슬라이더를 끄는 동안 모델에 바로 반영됩니다. 끌기 한 번이 되돌리기 한 단계입니다.
- `초기화` 단추로 기본값으로 되돌립니다.
- 히스토그램은 레이어를 바꿀 때와 값을 놓을 때 한 번 갱신됩니다.

조정 레이어 위에서 아래로 합치면 바로 아래 레이어에만 적용됩니다. 조정 레이어 쪽으로 위로 합치는 것은 거부됩니다.

## 레이어 효과

레이어 효과는 3종입니다.

| 효과 | 설정 |
|---|---|
| 그림자 | 각도, 거리, 확산, 크기, 색, 불투명도, 혼합 모드 |
| 색상 오버레이 | 색, 불투명도, 혼합 모드 |
| 획 | 위치, 크기, 색, 불투명도, 혼합 모드 |

**열기**: 레이어 우클릭 → `레이어 효과…`, 또는 잠금 줄의 `fx` 버튼. 왼쪽 목록에서 효과를 켜고 오른쪽에서 값을 고칩니다.

- 그림자 각도는 그림자가 **움직이는** 방향입니다. 0이 오른쪽이고 반시계 방향으로 커집니다. Shift를 누르면 15도 단위로 움직입니다.
- 거리 슬라이더는 500까지입니다.
- 창 아래의 `모두 끄기`/`모두 켜기`는 효과를 지우지 않고 한꺼번에 끕니다. `효과 지우기`는 효과 값을 없앱니다.
- `효과를 픽셀로 굽기`는 효과를 레이어 픽셀에 굽습니다. 불투명도도 픽셀에 구워지고 레이어는 100%가 됩니다.
- 조정 레이어와 잠긴 레이어에서는 효과 메뉴가 흐려지고 이유가 보입니다.

![효과 창](/img/captures/layers-effects-window.png)

![효과 3종 적용 예](/img/captures/layers-effects-three.png)

## 필터

창의 `⋯` 메뉴에서 `필터`를 고릅니다. 필터 메뉴는 아홉 항목입니다.

| 필터 | 주요 설정 |
|---|---|
| 가우시안 흐림 | 반경 |
| 모션 흐림 | 각도, 거리 |
| 언샵 마스크 | 반경, 양, 임계값 |
| 노이즈 추가 | 양, 가우시안 분포, 단색 |
| 중간값 | 반경 (정수) |
| 모자이크 | 칸 크기 |
| 하이패스 | 반경 |
| 오프셋 | 가로 이동, 세로 이동, 반대쪽으로 이어붙이기 |
| 높이를 노멀로 | 요철 세기. 칠한 높이를 노멀 맵으로 바꿉니다. [3D 작업](/guides/3d#높이를-노멀로-필터) 참고 |

필터 창에서 값을 고치면 모델에 미리보기가 나옵니다.

1. 값을 고릅니다. 미리보기 체크로 켜고 끕니다.
2. `Enter`를 누르면 적용됩니다. 되돌리기 한 단계입니다.
3. `Esc`나 창 닫기는 원래대로 돌립니다.

UV 섬 밖은 번지지 않습니다. 미리보기 중에는 칠하기, 레이어 편집, 되돌리기가 막힙니다. 활성 레이어를 바꾸거나 저장하면 미리보기가 자동으로 취소됩니다.

다음 경우에는 필터를 쓸 수 없습니다. 메뉴가 흐려집니다.

- 레이어가 없거나, 조정 레이어이거나, 폴더 또는 채널 폴더입니다.
- 잠겼거나 숨긴 레이어입니다.
- 마스크 면이나 퀵 마스크를 칠하는 중입니다.
- 투명도 잠금이 켜진 레이어입니다.

![필터 창](/img/captures/layers-filter-window.png)

## 히스토리 패널

히스토리 행을 누르면 그 단계로 갑니다. 여러 단계를 되돌리기와 다시 하기로 한 번에 넘깁니다. 앞 단계는 흐리게 보입니다. 필터 미리보기 중에는 이동이 막힙니다.

## 복제와 병합

| 동작 | 키 | 설명 |
|---|---|---|
| 아래와 결합 | `Ctrl+E` | 활성 레이어를 바로 아래 레이어와 합칩니다. 결과는 아래 레이어의 블렌드, 불투명도, 보임, 클리핑을 받습니다 |
| 보이는 것 합치기 | 우클릭 메뉴 | 같은 폴더에서 **이어진** 보이는 레이어를 합칩니다. 사이에 숨긴 레이어가 있으면 거부됩니다 |
| 효과를 픽셀로 | 효과 창 | 위의 레이어 효과 절을 봅니다 |

복제는 레이어 메뉴의 `복제`로 합니다. 복제하면 마스크도 같이 복사됩니다. 합치기는 되돌리기 한 단계입니다.

## 자동 레이어 나누기

텍스처를 색과 위치 규칙으로 부위별 폴더로 나눕니다. 의상 텍스처 한 장을 피부, 천, 장식으로 나눠 따로 칠할 때 씁니다.

**열기**: 창의 `⋯` 메뉴 또는 레이어 우클릭 메뉴의 `자동 레이어 나누기…`. 메뉴 `Tools/StudioRaming/MingPainter/Auto Split Layers…`로도 엽니다. 문서가 없거나 픽셀이 없는 문서, 채널 문서에서는 흐려집니다.

### 순서

1. **입력**을 고릅니다: `원본 파일`, `편집 중 캔버스`, `임포트 결과`. 임포트 결과가 파일과 다르면 노란 줄로 알려 줍니다.
2. **제안**을 누릅니다. 이미지에서 부위 규칙을 만듭니다. 현재 규칙은 대체됩니다.
3. 미리보기에서 `부위색 겹치기`로 구역을 확인합니다. 휠로 확대하고 가운데 버튼으로 옮깁니다. 부위를 누르면 선택됩니다.
4. 필요하면 규칙을 고칩니다.
   - `클릭 분할`을 켜고 미리보기를 누르면 선택한 부위에서 그 색을 따로 떼어 새 부위로 만듭니다.
   - `병합`: 부위 하나를 고르고 Ctrl+클릭으로 둘째를 골라 합칩니다.
   - `이름`, `위`/`아래`(우선순위와 레이어 순서), 색상·채도·명도 허용치를 고칩니다.
5. **적용**을 누릅니다.

### 적용하면 생기는 것

부위마다 폴더가 하나씩 생깁니다. 규칙 순서의 첫 부위가 맨 위에 옵니다.

- 폴더에는 마스크가 붙습니다.
- 폴더 안에 `원본 픽셀`(원본에서 그 부위만 남긴 것)과 그 위에 클리핑된 빈 `칠` 레이어가 있습니다.
- 원래 레이어는 숨겨지고 맨 아래로 갑니다. 지워지지 않습니다.
- 적용 전체가 되돌리기 한 단계입니다.

### 설정

| 설정 | 뜻 |
|---|---|
| 출력 크기 | 마스크 해상도. 문서 크기, 1/2, 1/4. 줄이면 가장자리가 거칠어집니다 |
| 최소 영역 | 이보다 작은 점 영역은 이웃 부위로 합칩니다 (0이면 끔) |
| 부위마다 가장 큰 영역 보존 | 켜면 작은 부위도 사라지지 않습니다 |

### 다시 만들기

규칙을 바꾼 뒤 `재생성`을 누르면 이전 나누기의 폴더를 찾아 마스크와 `원본 픽셀`만 새로 만듭니다. `칠` 레이어의 그림, 폴더 이름, 순서는 그대로입니다. 사라진 부위의 폴더는 지우지 않고 남깁니다.

### 규칙 저장과 RGB 마스크

- `규칙 저장…`, `규칙 불러오기…`로 규칙을 파일로 주고받습니다.
- `RGB 마스크 내보내기…`는 부위 세 개를 R, G, B 채널에 담은 PNG로 저장합니다. 파일 이름은 `<원본텍스처>_parts<번호>.png`입니다.
- 첫 시트를 재질의 활성 텍스처 칸에 연결할 수 있습니다. 재질이 읽기 전용이면 연결되지 않고 파일만 저장됩니다.

## 이 판에 없는 것

문서는 한 변 4096 픽셀까지입니다. 경사·엠보스 효과, 새틴, 스마트 오브젝트, 16비트 이미지는 지원하지 않습니다.
