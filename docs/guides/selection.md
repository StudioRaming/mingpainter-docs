# 선택

**이 문서를 읽으면** 선택 도구로 칠할 영역을 정하고, 선택을 합치고 다듬고, 자동 선택으로 비슷한 색 영역을 고를 수 있습니다.

선택 영역이 있으면 붓, 흐리기, 문지르기, 색 섞기가 **선택 안에서만** 바뀝니다.

## 선택 도구

선택 도구(`M`)에는 서브툴이 여덟 개 있고, 자동 선택(`W`)이 하나 더 있습니다.

| 도구 | 서브툴 | 쓰는 법 |
|---|---|---|
| 선택 (`M`) | 사각형 선택 | 끌어서 사각형을 고릅니다 |
| 선택 (`M`) | 타원 선택 | 끌어서 타원을 고릅니다 |
| 선택 (`M`) | 올가미 | 끌어서 자유 곡선으로 에워쌉니다 |
| 선택 (`M`) | 다각형 선택 | 점을 차례로 눌러 다각형을 만듭니다. 첫 점 근처에서 놓으면 닫힙니다 |
| 선택 (`M`) | 선택 브러시 | 칠한 곳을 선택에 더합니다 |
| 선택 (`M`) | 선택 지우개 | 칠한 곳을 선택에서 뺍니다 |
| 선택 (`M`) | UV 섬 | UV 섬 하나를 고릅니다 |
| 선택 (`M`) | 면 | 끌어서 지나간 면을 선택에 더합니다 |
| 자동 선택 (`W`) | 자동 선택 | 눌러서 비슷한 색 영역을 고릅니다 (마법봉) |

- **다각형 선택**: 점을 누를 때마다 고무줄 선이 따라옵니다. 첫 점 근처에서 놓으면 닫히고 선택이 확정됩니다. 첫 점 근처 범위는 Scene 뷰에서 8 픽셀, UV 캔버스에서 문서의 1%(최소 8 텍셀)입니다. `Esc`를 누르면 그리던 점을 모두 버립니다.
- **선택 브러시와 선택 지우개**는 일반 붓처럼 칠합니다. 직선(`Shift`)도 같습니다. `Alt`를 누르는 동안은 스포이트입니다. 크기 슬라이더를 씁니다.
- 나머지 선택 도구는 크기 슬라이더를 쓰지 않아 브러시 막대에서 슬라이더가 사라집니다.

Scene 뷰에서 사각형, 타원, 올가미, 다각형은 화면에 보이는 모양을 모델 표면으로 옮깁니다. 앞면만 고르는 기본 설정에서는 카메라를 향한, 가려지지 않은 면만 선택됩니다. UV 캔버스에서는 UV 위의 모양이 그대로 선택됩니다.

## 선택 속성

도구 속성의 `선택` 구역입니다.

| 속성 | 뜻 |
|---|---|
| 선택 모양 | 사각형, 타원, 올가미, 다각형, 브러시로 선택, 브러시로 해제, UV 섬, 면, 자동 선택 |
| 뒷면까지 관통 | 끄면 보이는 앞면만 선택합니다. 켜면 뒤쪽 메쉬까지 선택합니다 |
| 안티앨리어싱 | 선택 가장자리를 부드럽게 합니다. 끄면 가장자리가 딱 떨어집니다 |

![앞면만과 뒷면까지 관통 비교](/img/captures/select-through-backfaces.png)

## 수정키

선택 도구를 누르는 순간 눌려 있던 키가 선택을 합치는 방법을 정합니다.

| 키 | 결과 |
|---|---|
| 없음 | 기존 선택을 새 선택으로 바꿉니다 |
| `Shift` | 기존 선택에 더합니다 |
| `Alt` | 기존 선택에서 뺍니다 |
| `Shift` + `Alt` | 기존 선택과 겹치는 부분만 남깁니다 (교집합) |

`Ctrl`은 이 규칙을 바꾸지 않습니다. 드래그 한 번이 되돌리기 한 단계(`선택`)입니다. 레이어 썸네일을 Ctrl+클릭해서 선택을 만들 때도 같은 규칙입니다. → [레이어](/guides/layers)

![수정키로 선택 합치기](/img/captures/select-modifiers.png)

## 자동 선택 (마법봉)

눌러서 비슷한 색의 이어진 영역을 선택합니다. 자동 선택에서 쓰는 속성은 `채우기` 구역의 것입니다.

| 속성 | 뜻 |
|---|---|
| 허용 오차 | 얼마나 다른 색까지 같은 영역으로 볼지 |
| 틈 닫기 | 영역을 가르는 얇은 선의 틈을 몇 픽셀까지 닫을지 |
| 영역 확장 | 고른 영역을 가장자리 쪽으로 넓힙니다 |
| 안티앨리어싱 | 가장자리를 부드럽게 합니다 |
| 섬 안쪽만 | 누른 곳이 속한 UV 섬 안으로 제한합니다 |
| 참조 대상 | 현재 레이어, 모든 레이어 |

`섬 안쪽만`을 켜고 UV 섬 밖을 누르면 선택되지 않고 상태 줄에 알려 줍니다. 틈 닫기를 크게 하면 계산이 느려집니다. 4096 문서에서 틈 닫기 2픽셀에 몇 초가 걸린 측정이 있습니다.

![UV 섬·면 선택과 자동 선택](/img/captures/select-island-face-wand.png)

## 선택 명령

선택이 있으면 아래 명령을 씁니다. 선택 바나 창 `⋯` 메뉴의 `선택` 하위 메뉴에서 고릅니다.

| 명령 | 기본 키 | 하는 일 |
|---|---|---|
| 선택 해제 | `Ctrl+D` | 선택을 모두 지웁니다 |
| 선택 영역 반전 | `Ctrl+Shift+I` | 선택된 곳과 선택되지 않은 곳을 바꿉니다. 선택이 없으면 전체 선택이 됩니다 |
| 확장 | 없음 (키 할당 가능) | 선택을 바깥으로 넓힙니다. 값(px)을 묻습니다 |
| 축소 | 없음 (키 할당 가능) | 선택을 안쪽으로 좁힙니다. 값(px)을 묻습니다 |
| 흐림 | 없음 (키 할당 가능) | 선택 가장자리를 부드럽게 흐립니다. 값(px)을 묻습니다 |
| 채우기 | 없음 (키 할당 가능) | 선택 안을 그리는 색으로 채웁니다. `Alt`를 누르면 배경색입니다 |
| 지우기 | 없음 | 선택 안을 지웁니다 |
| 새 레이어로 | 없음 | 선택 안을 새 레이어로 복사하거나 잘라냅니다 |
| 전체 선택 | 없음 | 문서 전체를 선택합니다. 선택 바의 `기타 ▾`에 있습니다 |

- 확장과 축소는 정수 1~1024 픽셀, 흐림은 0.1~512 픽셀(소수점 한 자리)입니다. 마지막으로 쓴 값이 기억됩니다. 처음 값은 확장 1, 축소 1, 흐림 2 픽셀입니다.
- **지우기**: 색을 칠하는 중이면 선택 안의 투명도를 지웁니다. 마스크를 칠하는 중이면 마스크의 그 부분을 흰색으로 채웁니다. 퀵 마스크 중이면 선택을 해제합니다.
- **새 레이어로**: `복사해서`와 `잘라내서` 중에서 고릅니다. 잘라내기는 원래 자리에 구멍을 남기고, 새 레이어와 구멍이 한 단계로 되돌려집니다.
- `Ctrl+A`(모두 선택)는 **레이어 여러 개 선택**입니다. 픽셀 전체를 선택하지 않습니다. 문서 전체를 선택하려면 선택 바 `기타 ▾`의 `전체 선택`을 씁니다.
- 선택 명령은 모두 되돌리기 한 단계입니다.

큰 문서에서 확장, 축소, 흐림은 시간이 걸립니다. 4096 문서에서 4~8 픽셀을 처리하는 데 약 2초가 걸린 개발 PC 측정이 있습니다.

다음 경우에는 명령이 흐려지고 이유가 붙습니다. 선택 영역이 없음(반전은 제외), 잠긴 레이어, 폴더, 조정 레이어입니다. 복사는 잠긴 레이어에서도 됩니다.

## 선택 바

선택 도구를 쓰거나 선택이 있을 때 선택 바가 나옵니다. Scene 뷰에서는 서브툴 띠 위에, UV 캔버스에서는 아래쪽 도구 띠 오른쪽에 있습니다.

묶음은 네 개입니다.

1. 해제, 반전
2. 확장, 축소, 흐림
3. 채우기, 지우기
4. 새 레이어로 ▾, 기타 ▾

`기타 ▾`에는 점선 표시, 전체 선택, 퀵 마스크가 있습니다. 폭이 320 미만이면 아이콘만 보이고, 이름은 마우스를 올리면 나옵니다. 폭이 더 좁으면 줄이 바뀝니다.

## 선택 점선과 바깥 어둡게

UV 캔버스에서는 선택 가장자리에 흰색과 검정이 번갈아 움직이는 점선이 보이고, 선택 밖이 20% 어둡게 덮입니다. 선택 바 `기타 ▾`의 `점선 표시`를 끄면 둘 다 사라집니다.

Scene 뷰에서는 선택 가장자리를 화면 기준 1px 점선으로 그립니다. 줌과 상관없이 같은 굵기로 보입니다. 기본은 켜짐입니다.

문서가 4K 이상이면 어두운 가장자리가 최대 4텍셀 어긋날 수 있습니다. 선택 둘레가 26만 텍셀을 넘으면 점선이 솎아져 보입니다.
