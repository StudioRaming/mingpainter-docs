# 저장과 복구

**이 문서를 읽으면** 어떤 파일이 저장되는지, 저장이 어디에 생기는지, 비정상 종료 뒤 작업을 되찾는 방법과 원래대로 되돌리는 방법을 알 수 있습니다.

## 저장 파일 세 가지

| 파일 | 언제 쓰나 | 무엇을 담나 |
|---|---|---|
| `<원본이름>_paint.png` | 저장할 때 (`Ctrl+S`, 창의 저장 버튼, 우클릭 메뉴) | 칠한 텍스처. 문서 옆에 만듭니다 |
| `.mpd` | 저장할 때 함께 씁니다. 복구의 기준점이기도 합니다 | 레이어, 마스크, 조정, 효과, 되돌리기 정보 |
| 복구 폴더 | 획을 끝낼 때마다 자동 | 바뀐 타일을 일지(journal)로 쌓습니다 |

## 저장 순서와 위치

저장은 이 순서로 합니다.

1. `.mpd`를 씁니다.
2. `<이름>_paint.png`를 씁니다. 처음 저장이면 원본의 가져오기 설정을 복사합니다.
3. 재질의 텍스처 칸을 새 PNG로 연결합니다. Unity의 되돌리기로 되돌릴 수 있습니다.
4. 그 재질을 디스크에 씁니다.

모델 안에 들어 있어 읽기 전용인 재질은 PNG만 쓰고 연결하지 않습니다.

저장 폴더는 원본 텍스처가 어디 있느냐에 따라 다릅니다.

- 보통은 원본 옆에 만듭니다. 원본이 `Assets/` 밖이면 `Assets/MingPainter/`에 만듭니다.
- 원본이 셰이더 패키지가 가진 텍스처이거나 셰이더의 기본 텍스처이면 **재질 폴더**에 만듭니다. 셰이더를 업데이트할 때 작업 파일이 패키지 폴더에 섞이지 않게 하려는 것입니다. 재질이 `Assets/` 밖이면 `Assets/MingPainter/`입니다.
- 같은 이름의 `.mpd`나 `_paint.png`가 이미 있으면 이름 뒤에 ` 2`를 붙입니다.

## PNG 저장 규칙

- 원본 텍스처 파일은 절대 덮어쓰지 않습니다.
- 저장된 PNG는 원본을 디코드한 바이트와 같고, 바뀐 부분만 패딩을 넓힙니다. 바뀐 것이 없으면 원본과 바이트가 같습니다.
- 원본을 읽지 못하면 전체를 패딩하고 경고를 남깁니다.

## 복구

획을 끝낼 때마다 바뀐 타일이 복구 폴더에 쌓입니다. 다시 열면 기준점에 일지를 다시 적용해 마지막 상태로 돌아갑니다.

- 기준점은 마지막 저장 `.mpd`입니다. 저장하지 않은 문서는 문서를 만들 때 쓴 체크포인트 `.mpd`입니다. 원본 텍스처가 바뀌어도 복구됩니다.
- Play 모드로 들어가기 직전에 복구 기록을 먼저 씁니다. 그 동안 칠하기는 잠시 멈춥니다.

### 복구하기

Unity를 켠 뒤 창을 처음 열 때 복구할 작업이 있으면 `복구`, `나중에`, `버리기`를 묻습니다. 창의 목록 맨 위에 복구할 작업의 수가 나오고, 줄마다 복구와 버리기 단추가 있습니다. 손상된 기록은 버리기만 할 수 있습니다. 복구한 문서는 변경이 없어도 닫을 때 저장 여부를 묻습니다.

## 원래대로 되돌리기

MingPainter는 원본 파일을 바꾸지 않습니다. 되돌리는 방법은 두 가지입니다.

| 단추 | 하는 일 |
|---|---|
| 원래 텍스처로 | 재질 칸을 `.mpd`에 적어 둔 원본 텍스처로 되돌립니다. 문서는 열린 채로 남습니다. 되돌리기(Unity Undo)로 취소할 수 있습니다 |
| 원래 재질로 | 렌더러가 칠하던 재질 사본 대신 원래 재질을 다시 가리키게 합니다. 사본과 텍스처 파일은 남습니다 |
