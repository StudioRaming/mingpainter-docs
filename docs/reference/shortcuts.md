# 단축키

**이 문서를 읽으면** 칠하기 도구와 명령의 기본 키를 프리셋별로 확인할 수 있습니다.

프리셋은 두 가지입니다. `CSP`는 CLIP STUDIO PAINT의 키 배치를 따르고, `PS`는 Photoshop의 키 배치를 따릅니다. 두 표의 차이는 혼색 도구 키(`J`와 `R`)뿐입니다. 키는 설정 창의 `키 할당`에서 바꿀 수 있습니다. → [설정](/reference/settings#키-할당)

표는 제품 코드의 기본 키 설정에서 생성했습니다. 키 칸이 비어 있지 않은 명령만 나옵니다.

## CSP 프리셋 (기본)

| 명령 | 기본 키 | 설명 |
|---|---|---|
| 화면 회전 | `Space` |  |
| 화면 이동 | `Shift+Space` |  |
| 확대·축소 | `Ctrl+Space` |  |
| 스포이트 | `Alt` |  |
| 원형 팔레트 | `` ` `` |  |
| 실행 취소 | `Ctrl+Z` |  |
| 다시 실행 | `Ctrl+Shift+Z`, `Ctrl+Y` |  |
| 저장 | `Ctrl+S` |  |
| 브러시 작게 | `[` |  |
| 브러시 크게 | `]` |  |
| 주·보조 색 바꾸기 | `X` |  |
| 모두 선택 | `Ctrl+A` |  |
| 선택 해제 | `Ctrl+D` |  |
| 퀵 마스크 | `Q` |  |
| 선택 영역 반전 | `Ctrl+Shift+I` | 선택된 곳과 선택되지 않은 곳을 서로 바꿉니다 |
| 복사 | `Ctrl+C` | 선택 영역의 픽셀을 밍페인터 클립보드에 복사합니다 |
| 잘라내기 | `Ctrl+X` | 선택 영역의 픽셀을 클립보드에 복사하고 레이어에서 지웁니다 |
| 붙여넣기 | `Ctrl+V` | 클립보드의 픽셀을 현재 레이어 위에 변형 가능한 상태로 붙여넣습니다 |
| 자 전환 | `Ctrl+Alt+R` | 자를 표시 → 자+흡착 → 끔 순서로 바꿉니다 |
| 편집 확정 | `Ctrl+Enter` | 입력 중인 글자나 변형을 확정합니다 |
| 선택 영역 복원 | `Ctrl+Shift+D` | 직전에 해제한 선택 영역을 다시 불러옵니다 |
| 선택 숨기기 | `H` | 선택 영역을 숨기고 선택을 해제합니다. Ctrl+Shift+D로 되돌립니다 |
| 선택한 곳만 표시 | `Shift+H` | 선택 영역 밖을 숨깁니다 |
| 전부 표시 | `Alt+H` | 숨김을 모두 풉니다 |
| 새 레이어 | `Ctrl+Shift+N` |  |
| 아래로 합치기 | `Ctrl+E` |  |
| 레이어 지우기 | `Del` |  |
| 직선 긋기(클릭) | `Shift` |  |
| 브러시 크기(드래그) | `Ctrl+Alt` |  |
| 화면에서 색 가져오기 | `Shift+I` |  |
| 단축키 목록 | `F1` |  |
| 설정 열기 | `Ctrl+Shift+Alt+K` |  |
| 펜 | `P` |  |
| 붓 | `B` |  |
| 지우개 | `E` |  |
| 혼색: 흐리기·문지르기·색 섞기 | `J` |  |
| 채우기 | `G` |  |
| 도형 | `U` |  |
| 선택 | `M` |  |
| 자동 선택 | `W` |  |
| 이동·변형 | `V`, `Ctrl+T` |  |
| 텍스트 | `T` |  |
| 스포이트 · Alt 누르는 동안 | `I` |  |
