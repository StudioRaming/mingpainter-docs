# 설정

**이 문서를 읽으면** 설정 창의 탭이 무엇을 하는지, 키 할당과 브러시 라이브러리 위치를 어떻게 바꾸는지 알 수 있습니다.

설정은 Unity Preferences의 `StudioRaming/MingPainter` 페이지에 있습니다.

## 탭

| 탭 | 무엇을 하나 |
|---|---|
| 펜·입력 | 펜 입력 설정. 펜 보정(압력 보정)과 펜 진단 창을 여는 버튼이 있습니다 |
| 조작 | 화면 조작 설정 |
| 키 할당 | 프리셋(CSP·PS), 명령별 키, 키 지우기, 전체 초기화 |
| 그리기 | 칠하기 설정 |
| 라이브러리 | 브러시 라이브러리 위치, 기본 위치로 |

## 키 할당

- 프리셋을 바꾸기 전에 확인을 묻습니다. 전체 초기화도 확인을 묻습니다.
- Unity 단축키와 겹치면 알려 줍니다.
- 명령마다 키 칩이 있습니다. 칩의 `×`로 키를 빼고, `키 할당…`을 눌러 키 잡기 창에서 새 키를 누릅니다.
- 다른 명령이 이미 쓰는 키를 고르면 그 키를 옮길지 묻습니다. 겹침이 없으면 알림도 없습니다.
- 바꾼 행만 기본값으로 되돌릴 수 있습니다.

기본 키 표는 [단축키](/reference/shortcuts)에 있습니다.

## 라이브러리

브러시 라이브러리는 PC마다 하나입니다. 기본 위치는 `%APPDATA%\StudioRaming\MingPainter`입니다. 탭에서 지금 폴더를 보고, 폴더를 열고, 위치를 바꿀 수 있습니다.

위치를 바꾸면 이렇게 진행합니다.

1. 폴더를 고릅니다.
2. 고른 폴더가 비었거나 라이브러리가 아닌 파일만 있으면 `복사`, `복사 안 함(빈 폴더로 시작)`, 취소를 묻습니다. 복사는 있는 파일을 덮어쓰지 않습니다.
3. 고른 폴더에 이미 라이브러리가 있으면 `이 라이브러리 쓰기`를 묻습니다. 그 폴더에 복사하지 않습니다.
4. 지금 폴더 안이거나 지금 폴더를 품은 폴더는 거절합니다.

원래 폴더는 지워지지 않습니다. `기본 위치로` 행으로 기본 위치에 되돌립니다. 바꾼 위치가 사라지면(예: USB를 뺌) 이번 실행에는 기본 위치를 쓰고 상태 줄에 알려 줍니다.

## 언어

지원 언어는 한국어, English, 日本語입니다. 언어는 설정 탭이 아니라 창 제목 줄의 언어 메뉴에서 바꿉니다. 언어 설정은 StudioRaming 도구 전체가 같이 씁니다. 다른 StudioRaming 도구에서 언어를 바꾸면 이 제품도 따라 바뀝니다.
