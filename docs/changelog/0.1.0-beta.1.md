# 패치노트 0.1.0-beta.1

:::warning[클로즈드 베타]
0.1.0-beta.1은 클로즈드 베타 테스터에게만 드리는 버전입니다. 쓰기 전에 프로젝트를 꼭 백업해 주세요. 정식판에서 내용이 바뀔 수 있습니다.
:::

## 포함된 기능

- Unity 에디터 안에서 모델 텍스처 칸을 열어 Scene 뷰와 UV 캔버스에 칠하는 칠하기 창
- 펜, 붓, 에어브러시, 브러시 모음, 지우개, 채우기, 스포이트, 혼색, 그라데이션, 도형, 선택, 자동 선택, 이동·변형, 텍스트, 자, 데코·스탬프·무늬 도구
- 대칭, UV 이음새 넘어 칠하기, 뒷면까지 칠하기
- 레이어, 블렌드 모드 29종, 래스터 마스크, 퀵 마스크, 조정 레이어 12종, 레이어 효과 3종, 필터 9종, 히스토리
- 자동 레이어 나누기와 RGB 마스크 내보내기
- 3D 작업: 표시 범위(숨김)와 숨김 프리셋, 대칭 고급, 웨이트 선택, 표면 방향 흐림, AO 굽기, 요철(노멀) 도장 9종과 요철 칸, MaskMaker 마스크 선택, 메쉬 다시 임포트, 세트와 세트 메모리
- PSD 열기와 PSD로 내보내기
- 2D 캔버스 만들기, 스탬프 등록, 3D에 붙이기, UV 텍스처에 붙이기
- 브러시 가져오기(`.abr`, `.sut`, `.gpl`, 이미지, `.mpbrush`)
- 저장, 복구 기록, 원래 텍스처로 되돌리기
- 키 할당 프리셋(CSP, PS)과 한국어, English, 日本語 인터페이스
