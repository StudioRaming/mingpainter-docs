# 設定

**この文書を読むと** 設定ウィンドウのタブの働き、ショートカットの割り当てとブラシライブラリの場所の変え方がわかります。

設定は、Unity の Preferences にある `StudioRaming/MingPainter` のページにあります。

## タブ

| タブ | 役割 |
|---|---|
| ペン・入力 | ペン入力の設定。ペン補正（筆圧補正）と、ペンの診断ウィンドウを開くボタンがあります |
| 操作 | 画面の操作の設定 |
| ショートカット | プリセット（CSP・PS）、コマンドごとのキー、キーのクリア、全体のリセット |
| 描画 | 描画の設定 |
| ライブラリ | ブラシライブラリの場所、既定の場所に戻す |

## ショートカット {#키-할당}

- プリセットを変える前に確認を尋ねます。全体のリセットも確認を尋ねます。
- Unity のショートカットと重なる場合は知らせます。
- コマンドごとにキーのチップがあります。チップの `×` でキーを外し、`ショートカットを割り当て…` を押して、キー取得のウィンドウで新しいキーを押します。
- 他のコマンドが既に使っているキーを選ぶと、そのキーを移すかどうかを尋ねます。重なりがなければ通知は出ません。
- 変更した行だけを既定の値に戻せます。

既定のキーの表は [ショートカット](/reference/shortcuts) にあります。

## ライブラリ {#라이브러리}

ブラシライブラリは PC ごとに 1 つです。既定の場所は `%APPDATA%\StudioRaming\MingPainter` です。タブでは、今のフォルダーを表示し、フォルダーを開き、場所を変更できます。

場所を変更すると、次の順で進みます。

1. フォルダーを選びます。
2. 選んだフォルダーが空であるか、ライブラリではないファイルだけがある場合は、`コピー`、`コピーしない（空のフォルダーで始める）`、キャンセルを尋ねます。コピーは、既にあるファイルを上書きしません。
3. 選んだフォルダーに既にライブラリがある場合は、`このライブラリを使う` を尋ねます。そのフォルダーにはコピーしません。
4. 今のフォルダーの中、または今のフォルダーを含むフォルダーを選んだ場合は、拒否します。

元のフォルダーは削除されません。`既定の場所に戻す` の行で、既定の場所に戻せます。変更した場所がなくなった場合（例: USB を抜いた）は、この実行では既定の場所を使い、ステータス行で知らせます。

## 言語

対応言語は、韓国語、English、日本語です。言語は設定のタブではなく、ウィンドウのタイトルバーにある言語メニューで変更します。言語の設定は StudioRaming のツールすべてで共有されます。ほかの StudioRaming のツールで言語を変えると、この製品も一緒に変わります。
