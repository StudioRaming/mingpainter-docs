# ショートカット

**この文書を読むと** 描画ツールとコマンドの既定のキーを、プリセットごとに確認できます。

プリセットは 2 種類です。`CSP` は CLIP STUDIO PAINT のキー配置に従い、`PS` は Photoshop のキー配置に従います。2 つの表の違いは、色混ぜツールのキー（`J` と `R`）だけです。キーは設定ウィンドウの `ショートカット` で変更できます。→ [設定](/reference/settings#키-할당)

表は製品コードの既定のキー設定から生成しました。キーの欄が空でないコマンドだけを載せています。

## CSP プリセット（既定）

| コマンド | 既定のキー | 説明 |
|---|---|---|
| 画面の回転 | `Space` |  |
| 画面の移動 | `Shift+Space` |  |
| 拡大・縮小 | `Ctrl+Space` |  |
| スポイト | `Alt` |  |
| 丸いパレット | `` ` `` |  |
| 元に戻す | `Ctrl+Z` |  |
| やり直し | `Ctrl+Shift+Z`、`Ctrl+Y` |  |
| 保存 | `Ctrl+S` |  |
| ブラシを小さく | `[` |  |
| ブラシを大きく | `]` |  |
| 描画色と背景色を入れ替え | `X` |  |
| すべて選択 | `Ctrl+A` |  |
| 選択解除 | `Ctrl+D` |  |
| クイックマスク | `Q` |  |
| 選択範囲を反転 | `Ctrl+Shift+I` | 選択された部分と選択されていない部分を入れ替えます |
| コピー | `Ctrl+C` | 選択範囲のピクセルを MingPainter のクリップボードにコピーします |
| 切り取り | `Ctrl+X` | 選択範囲のピクセルをクリップボードにコピーし、レイヤーから消します |
| 貼り付け | `Ctrl+V` | クリップボードのピクセルを、現在のレイヤーの上に変形できる状態で貼ります |
| 定規の切り替え | `Ctrl+Alt+R` | 定規を表示 → 定規と吸着 → オフの順に切り替えます |
| 編集を確定 | `Ctrl+Enter` | 入力中の文字や変形を確定します |
| 選択範囲を復元 | `Ctrl+Shift+D` | 直前に解除した選択範囲を読み込み直します |
| 選択を隠す | `H` | 選択範囲を隠し、選択を解除します。Ctrl+Shift+D で戻せます |
| 選択した部分だけ表示 | `Shift+H` | 選択範囲の外を隠します |
| すべて表示 | `Alt+H` | 非表示をすべて解除します |
| 新規レイヤー | `Ctrl+Shift+N` |  |
| 下のレイヤーと結合 | `Ctrl+E` |  |
| レイヤー消去 | `Del` |  |
| 直線を引く（クリック） | `Shift` |  |
| ブラシサイズ（ドラッグ） | `Ctrl+Alt` |  |
| 画面から色を取り込む | `Shift+I` |  |
| ショートカットの一覧 | `F1` |  |
| 設定を開く | `Ctrl+Shift+Alt+K` |  |
| ペン | `P` |  |
| 筆 | `B` |  |
| 消しゴム | `E` |  |
| 色混ぜ: ぼかし・指先・色混ぜ | `J` |  |
| 塗りつぶし | `G` |  |
| 図形 | `U` |  |
| 選択 | `M` |  |
| 自動選択 | `W` |  |
| 移動・変形 | `V`、`Ctrl+T` |  |
| テキスト | `T` |  |
| スポイト · Alt を押している間 | `I` |  |
