# パッチノート 0.1.0

:::warning[公開前の文書]
このパッチノートは 0.1.0 公開前の草稿です。以下の内容は、実装とオフライン試験が完了した機能です。Unity の実機確認と公開はまだ完了していません。
:::

## 含まれる機能

- Unity エディター内でモデルのテクスチャスロットを開き、Scene ビューと UV キャンバスに描く描画ウィンドウ
- ペン、筆、エアブラシ、ブラシ集、消しゴム、塗りつぶし、スポイト、色混ぜ、グラデーション、図形、選択、自動選択、移動・変形、テキスト、定規、デコレーション・スタンプ・パターンのツール
- 対称、UV の継ぎ目を越えた描画、裏面までの描画
- レイヤー、合成モード 29 種、ラスターマスク、クイックマスク、調整レイヤー 12 種、レイヤーエフェクト 3 種、フィルター 9 種、ヒストリー
- レイヤーの自動分割と RGB マスクの書き出し
- 3D 作業: 表示範囲（非表示）と非表示プリセット、ミラー詳細、ウェイト選択、面方向のぼかし、AO ベイク、凹凸（法線）のスタンプ 9 種と凹凸スロット、MaskMaker マスクの選択、メッシュの再読み込み、セットとセットのメモリ
- PSD の読み込みと PSD への書き出し
- 2D キャンバスの作成、スタンプ登録、3D への貼り付け、UV テクスチャへの貼り付け
- ブラシの読み込み（`.abr`、`.sut`、`.gpl`、画像、`.mpbrush`）
- 保存、復元の記録、元のテクスチャに戻す
- キー割り当てのプリセット（CSP、PS）と、韓国語、English、日本語のインターフェース
