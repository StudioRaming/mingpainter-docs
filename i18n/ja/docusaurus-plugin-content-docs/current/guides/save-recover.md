# 保存と復元

**この文書を読むと** どのファイルが保存されるか、保存先がどこになるか、異常終了の後で作業を取り戻す方法と、元の状態に戻す方法がわかります。

## 保存するファイルの 3 種類

| ファイル | いつ書くか | 何を含むか |
|---|---|---|
| `<元の名前>_paint.png` | 保存するとき（`Ctrl+S`、ウィンドウの保存ボタン、右クリックメニュー） | 描いたテクスチャ。文書の横に作られます |
| `.mpd` | 保存するときに一緒に書きます。復元の基準点でもあります | レイヤー、マスク、調整、エフェクト、元に戻す情報 |
| 復元フォルダー | ストロークを終えるたびに自動で | 変わったタイルを日誌（journal）として積み重ねます |

## 保存の順序と場所 {#저장-순서와-위치}

保存は次の順序で行います。

1. `.mpd` を書きます。
2. `<名前>_paint.png` を書きます。初めての保存では、元のインポート設定をコピーします。
3. マテリアルのテクスチャスロットを新しい PNG に接続します。Unity の元に戻すで取り消せます。
4. そのマテリアルをディスクに書き込みます。

モデルに含まれていて読み取り専用のマテリアルは、PNG だけを書き、接続はしません。

保存フォルダーは、元のテクスチャがどこにあるかによって異なります。

- 通常は、元のファイルの横に作ります。元のファイルが `Assets/` の外にある場合は、`Assets/MingPainter/` に作ります。
- 元のテクスチャがシェーダーパッケージの持つテクスチャ、またはシェーダーの既定のテクスチャである場合は、**マテリアルのフォルダー** に作ります。シェーダーを更新したときに、作業ファイルがパッケージのフォルダーに混ざらないようにするためです。マテリアルが `Assets/` の外にある場合は、`Assets/MingPainter/` です。
- 同じ名前の `.mpd` や `_paint.png` が既にある場合は、名前の後ろに ` 2` を付けます。

## PNG 保存のルール

- 元のテクスチャファイルは、決して上書きしません。
- 保存された PNG は、元の画像をデコードしたバイト列と同じで、変わった部分だけパディングを広げます。何も変わっていなければ、元のファイルとバイト列が同じです。
- 元の画像を読み込めない場合は、全体をパディングして警告を残します。

## 復元 {#복구}

ストロークを終えるたびに、変わったタイルが復元フォルダーに積み重なります。もう一度開くと、基準点に日誌を適用して、最後の状態に戻ります。

- 基準点は、最後に保存した `.mpd` です。一度も保存していない文書は、文書を作成したときのチェックポイントの `.mpd` になります。元のテクスチャが変わっていても復元されます。
- Play モードに入る直前に、復元の記録を先に書き込みます。その間、描画は一時的に止まります。

### 復元する

Unity を起動してウィンドウを初めて開いたとき、復元できる作業があれば `復元`、`あとで`、`破棄` を尋ねます。ウィンドウの一覧の一番上に、復元できる作業の数が表示され、行ごとに復元と破棄のボタンがあります。破損した記録は、破棄しかできません。復元した文書は、変更がなくても閉じるときに保存するかどうかを尋ねます。

## 元の状態に戻す {#원래대로-되돌리기}

MingPainter は元のファイルを変更しません。元に戻す方法は 2 つあります。

| ボタン | 働き |
|---|---|
| 元のテクスチャに戻す | マテリアルのスロットを、`.mpd` に記録してある元のテクスチャに戻します。文書は開いたままです。Unity の元に戻す（Undo）で取り消せます |
| 元のマテリアルに戻す | レンダラーが描いていたマテリアルのコピーの代わりに、元のマテリアルを再び参照させます。コピーとテクスチャファイルは残ります |
