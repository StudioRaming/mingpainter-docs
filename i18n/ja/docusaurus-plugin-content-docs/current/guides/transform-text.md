# 変形・テキスト・定規・スタンプ

**この文書を読むと** 絵を移動、拡大、回転し、文字をレイヤーとして書き、定規で線を揃え、装飾や模様を押せるようになります。

## 変形

移動・変形ツール（`V`、`Ctrl+T`）は、選択した範囲を浮いた絵として持ち上げ、移動、拡大、回転します。選択がなければ、レイヤー全体が対象です。確定するまで、レイヤーのピクセルは変わりません。

### 変形のモード

| モード | 働き |
|---|---|
| 拡大・縮小・回転 | 角をドラッグしてサイズを変えます。角の外側をドラッグすると回転します。`Shift` で縦横比を解除し、回転は 15 度単位になります。`Alt` は中心基準です |
| 自由変形 | 4 つの角をそれぞれ個別に動かします |
| ワープ | 格子点をドラッグして面を歪ませます。格子は 3×3、4×4、5×5 から選びます |

変形のバーには、モードが 3 つ、`左右反転`、`上下反転`、ワープのときだけ格子が 3 つ、`確定`、`キャンセル` があります。幅が狭くなると、まとまり単位で行が折り返されます。

- 確定は `Enter`、キャンセルは `Esc` です。確定は `変形` の 1 段階で元に戻せます。
- 別のツールを選ぶと、変形が確定されます。変形中は別のレイヤーを選べません。先に `Enter` または `Esc` を押してください。
- ロックされたレイヤー、フォルダー、透明度をロックしたレイヤー、マスクの面、クイックマスクでは、変形を始められません。ステータス行に理由が表示されます。

### 画面基準で 3D に貼る

Scene ビューの右クリックメニューで `画像を追加…` を選ぶと、画像ファイルを選べ、Scene ビューから見たモデルの表面に投影される変形ボックスが開きます。最初のフレームは Scene ビューの中央に置かれ、画面の 60% より大きい場合は縮小されます。カメラを回しても、絵は最初に見た角度のまま貼られます。

## コピー、切り取り、貼り付け

| コマンド | 既定のキー | 働き |
|---|---|---|
| コピー | `Ctrl+C` | 選択範囲のピクセルを MingPainter のクリップボードに入れます。レイヤーは変わりません |
| 切り取り | `Ctrl+X` | コピーしてから同じ場所を消します。1 段階で元に戻せます |
| 貼り付け | `Ctrl+V` | クリップボードの絵を現在のレイヤーの上に、変形できる状態で貼ります。確定すると `貼り付け` の 1 段階です |

- MingPainter のクリップボードは、プログラム内でのみ使います。OS のクリップボードではありません。
- 切り取りは、ロックされたレイヤーと透明度をロックしたレイヤーでは拒否されます。クイックマスク中は、コピーと切り取りが拒否されます。
- クリップボードが空の場合、`貼り付ける内容がありません。先にコピーしてください` と表示されます。

### 画像を追加

画像ファイルを新しいレイヤーとして読み込み、変形できる状態で貼ります。メニューは 2 種類あります。

- `画像を追加…`: モデルの上に貼ります。上の 3D 投影を使います。
- `画像を UV に貼り付け…`: UV テクセルの平面に貼ります。

2 つのメニューは、Scene ビューと UV キャンバスの右クリックメニューにあります。PNG、JPG、TGA、BMP、GIF（最初のフレーム）を読み込めます。長辺が 8192 ピクセルを超えると失敗します。WebP には対応していません。履歴には `画像を追加` と記録されます。

## テキスト

テキストツール（`T`）は、キャンバスを押すと入力を始めます。確定すると文字レイヤーになります。文字のウィンドウは、入力を始めるときに一緒に開きます。

### 文字のウィンドウ

| ブロック | 働き |
|---|---|
| 範囲 | `選択した文字に適用` または `続けて書く文字に適用（選択なし）`。選択した文字の値が異なる場合は、`文字ごとに値が異なります` と表示されます |
| フォント | 検索欄付きの一覧です。先頭の項目が既定のフォントです。一覧にないフォントは、既定のフォントで描きます |
| サイズ、色、太字、斜体 | 範囲に合う文字だけに適用します |
| 縦書き、パスに沿って配置 | 縦に書くか、描いた線に沿って書きます |
| 行間、字間、配置 | 行の間、文字の間、左・中央・右の揃えです。縦書きでは上・中央・下です |
| 縁取り | 太さと色 |
| 確定、キャンセル、ラスタライズ | 下の `確定とラスタライズ` を参照してください |

- 文字を選択すると、選んだランで変更した項目だけが変わります。他の色やサイズはそのまま残ります。
- 選択がない場合は、続けて書く文字に適用されます。

![文字のウィンドウ](/img/captures/text-window.png)

![文字のウィンドウ（狭い幅）](/img/captures/text-window-narrow.png)

### 入力とキー

- 入力中の IME の変換文字は下線で表示され、確定するまで文字レイヤーには入りません。下線とキャレットは UV キャンバスでのみ表示されます。
- `Ctrl+Enter` は確定です。`Esc` を 2 回押すとキャンセルです。最初の `Esc` は入力を止めます。状態チップに現在のキーが表示されます。
- 文字を入力していない場合は、レイヤーを作りません。

![文字の入力とキャレット](/img/captures/text-caret-uv.png)

### 縦書きとパスに沿った配置

- 縦書きでは、韓国語、漢字、かなは立てて書き、ラテン文字と数字は横に寝かせて書きます。
- `パスに沿って配置` をオンにして、Scene ビューのモデル表面または UV キャンバスでドラッグすると線が描かれ、文字がその線に沿って並びます。線が短すぎると `パスが短すぎます` と表示されます。モデルの表面がない場所を押すと `クリックした場所にモデルの表面がありません` と表示されます。

### 確定とラスタライズ

- `Ctrl+Enter` で確定すると、文字レイヤーになります。文字レイヤーは文字のデータを持っているため、後から直せます。
- `ラスタライズ` ボタンは、文字レイヤーを通常のピクセルに変えます。変えたあとは、文字を直せません。
- 文字の上にピクセルを描いてから再び確定すると、文字を描き直す際にそのピクセルは消えます。ステータス行がそれを知らせます。
- 文字は色のレイヤーにのみ書けます。マスクの編集中とクイックマスク中は書けません。
- フォントが見つからない場合は、別のフォントで描き、`フォントが見つからないため、別のフォントで描きました` と知らせます。

## 定規

定規ツールは、描いた線を直線、曲線、平行線、同心円、放射線に揃えます。定規の種類はサブツールの 5 つです。

| 定規 | 形 |
|---|---|
| 直線定規 | 2 点を通る直線です。ビューの端まで伸びます |
| 曲線定規 | 打った点の間を通る曲線です |
| 平行線定規 | 平行線のガイドを描きます |
| 同心円定規 | 同心円のガイドを描きます |
| 放射線定規 | 1 点から出る放射線のガイドを描きます |

### 作成と移動

- 定規ツールで画面を押したままドラッグすると、定規が作られます。定規がない場合、チップに `定規がありません。定規サブツールで画面に描いて作ります` と表示されます。
- 定規のハンドルをドラッグすると、定規が移動します。
- 定規はビューごとに 1 つです。Scene ビューに 1 つ、UV キャンバスの文書ごとに 1 つです。編集セッション内にのみ残り、`.mpd` ファイルには保存されません。

### モードチップと吸着

- 定規があると、上の中央にチップが表示されます。チップを押すたびに `定規を表示` → `定規を表示 + 吸着` → `定規オフ` の順に切り替わります。ショートカットは `Ctrl+Alt+R` です。
- 吸着をオンにすると、描いているストロークの点が定規から 16 ピクセル以内にあるとき、定規の上へ移動します。UV キャンバスではテクセル基準です。

## デコレーション・スタンプ・パターン

デコレーション・スタンプ・パターンのツールには、既定のキーがありません。キーはキー割り当てで決めます。

### デコレーション

デコレーションは、装飾の絵をブラシの先端として使うブラシです。標準のデコレーションには、`星`、`きらめき十字`、`ドットリング`、`葉の小枝`、`花びら`、`紙吹雪` などがあります。通常のブラシと同じように、押してドラッグして使います。

### スタンプ

- **登録**: 2D キャンバスのウィンドウの `⋯` メニューにある `スタンプとして登録…` で名前を付けて登録します。空の絵は登録されません。
- **一覧**: `スタンプ` のウィンドウがツールと一緒に開きます。一番上に数と上限が表示されます（例: 12 / 60、上限は 60）。いっぱいになると `スタンプがいっぱいです` と案内されます。行を押すと選択され、`クリア` は確認を尋ねます。
- **プロパティ**: `スタンプを選ぶ`、`描画色で塗る`（既定でオン）、`プレビューを表示`（既定でオン）。プレビューは、ポインターの上の半透明の絵と、進行方向の次の位置の絵です。

![スタンプのウィンドウ](/img/captures/stamp-window.png)

![スタンプのウィンドウがいっぱいの状態](/img/captures/stamp-window-full.png)

### パターン

- **標準の 8 種**: しずく、ずらしたしずく、ストライプ、チェック、ギンガムチェック、千鳥格子、アーガイル、細い格子。
- **マイパターン**: ユーザーのパターンがあるときだけ表示されます。
- **プロパティ**: `パターンを選ぶ`、`パターンの大きさ`（既定は 64 ピクセル）、`強度`（既定は最大）、`適用方法`（既定は乗算、外す、高さ）、`濃度を反転`（既定はオフ）。
