# PSD

**この文書を読むと** PSD ファイルをレイヤーごと開き、作業結果を PSD として書き出し、どこまでそのまま移せるかがわかります。

## PSD を開く

マテリアルのテクスチャスロットに `.psd` ファイルが接続されていると、そのスロットを開くときに PSD がレイヤーごと開きます。

- レイヤー、フォルダー、合成モード、マスク、調整レイヤーが、そのままレイヤーパネルに表示されます。
- その PSD の `.mpd` 作業ファイルが既にある場合は、PSD ではなく作業ファイルを開きます。
- 文書サイズは一辺 4096 ピクセルまでです。それより大きい場合は、文書が開かず、ステータス行に理由が表示されます。
- 読み込み中に見つかった問題は、警告ウィンドウにコードごとにまとめて表示されます。警告ごとに、該当するレイヤーの名前が付きます。

![PSD を開いた直後のレイヤーパネル](/img/captures/psd-open-layers.png)

![PSD の警告ウィンドウ](/img/captures/psd-warnings-window.png)

### 元の PSD は変わりません

PSD を開いて描いても、PSD ファイルには書き込まれません。保存すると `<名前>_paint.png` と `.mpd` ができます。PSD に書き戻すには、下の `PSD として書き出す` を使います。PSD で開いた文書は、「元のレイヤー」の判定がオフになります。

保存先は [保存と復元](/guides/save-recover) の保存フォルダーのルールに従います。

## PSD として書き出す

**開き方**: ウィンドウの `⋯` メニュー、またはレイヤーの右クリックメニューの `PSD として書き出す…`。文書が開いていて、書き出せる状態のときだけ有効になります。

書き出しウィンドウでオプションを 2 つ選び、`書き出し` を押します。どちらのオプションも既定でオンです。

| オプション | 意味 |
|---|---|
| エフェクトをラスタライズ | レイヤーエフェクトをレイヤーのピクセルに合成して書き出します。オフにすると、エフェクトは PSD に入りません |
| 色のバランス・特定色域の選択・色の置き換えをピクセルに | この 3 つの調整は、Photoshop の値へ正確には移せません。オンにすると、計算した結果をピクセルとして書き出します |

- 既定のファイル名は `<名前>_paint.psd` です。
- 書き出しは文書を変えません。元に戻す段階は作られません。
- 合成結果は、保存 PNG と同じ経路で作られます。
- 焼き込むレイヤーは、不透明度がピクセルに焼き込まれて 100% になります。合成モードは残ります。
- 既存の PSD に上書きする場合は、一時ファイルに書いてから置き換えます。失敗した場合は元のファイルが残ります。
- 書き出しが終わったあとに警告があれば、警告ウィンドウが開きます。

![PSD 書き出しのウィンドウ](/img/captures/psd-export-window.png)

## 往復の範囲

PSD を開いて再び書き出すとき、項目ごとにどこまで移せるかをまとめた表です。

| 項目 | 読み込み | 書き出し |
|---|---|---|
| レイヤー、フォルダー、パススルーのフォルダー | 対応 | 対応 |
| 合成モード 27 種 | 対応 | 対応 |
| クリッピング、不透明度 | 対応 | 対応（近似の項目あり） |
| 塗りの不透明度 | 対応 | 対応（特殊 8 種は近似） |
| マスク（ラスター） | 対応 | 対応 |
| 調整レイヤー | 対応 | 対応（上の 3 つの調整は、オプションに応じてピクセル） |
| レイヤーエフェクト（`lfx2`） | 8 種を読み込み | 読み込んだエフェクトは元のまま保持します。この製品のエフェクトは、ピクセルに焼き込むか省略します |
| ベベル、エンボス、サテン | 元のまま保持のみ | 元のまま保持のみ |
| ベクトルマスク、スマートオブジェクト | 編集しない | 編集しない |
| PSB、16・32 ビット、CMYK・Lab | 非対応 | 非対応 |

## 近似の項目

PSD へ移すときに、値がわずかに異なることがある項目です。書き出すときに警告で知らされます。

- クリッピングされたレイヤーをグループとして合成（オフがオンとして近似されます）
- クリッピングのベースの塗りの不透明度
- 塗りの不透明度の特殊 8 種

## 制限

- Mono 32 ビットと .NET 64 ビットの間では、合成結果が最大 1 ずれることがあります。
- 白いマット合成では、アルファが 128 未満の場所で色の誤差が大きくなります。Photoshop と同じ制限です。
