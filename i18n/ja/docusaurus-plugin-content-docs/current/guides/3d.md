# 3D 作業

**この文書を読むと** モデルの一部だけを描けるように隠し、左右対称の中心を合わせ、ボーンのウェイトから選択を作り、表面に沿ってぼかし、AO をベイクし、凹凸を法線マップに描き、複数のマテリアルをセットとして扱えます。

この文書の機能はすべて、モデル（3D レンダラー）を基準にしています。ほとんどのウィンドウは、ツールウィンドウの一覧から開きます。

## 表示範囲（非表示）

非表示は、**面（三角形）単位** で描ける場所を隠します。メッシュは変わりません。描画、選択、深度の計算からだけ、隠した面を除きます。

- 隠した面には描けません。隠した面は、奥の面を隠しません。
- **面の非表示**、**アイランドの非表示**、**オブジェクトの非表示** は別々に保存されます。3 つのうちどれか 1 つでも隠した面は、表示されません。
- 非表示は UV キャンバスにも適用されます。UV のストローク、平面グラデーション、UV の形の選択は、隠れた場所を飛ばします。

### キーとコマンド

3 つのキーは [ショートカット](/reference/shortcuts) の表にあります。

| コマンド | キー | 働き |
|---|---|---|
| 選択を隠す | `H` | 選択範囲の面を隠し、選択を解除します。`Ctrl+Shift+D` で選択を戻せます。選択がない場合は何も変えず、ステータス行で知らせます |
| 選択した部分だけ表示 | `Shift+H` | 選択範囲の外の面をすべて隠します。選択はそのまま残ります |
| すべて表示 | `Alt+H` | 面、アイランド、オブジェクトの非表示をすべて解除します |

同じコマンドは、ウィンドウのメニューの `表示範囲` の下にもあります。このメニューには `このアイランドを隠す`、`このアイランドだけ表示`、`反転`、`拡張`、`縮小`、`ウィンドウを開く` も並んでいます。

### 表示範囲のウィンドウ

| 画面の表示 | 働き |
|---|---|
| 選択した部分だけ表示 | 選択範囲の外の面を隠します |
| 選択を隠す | 選択範囲を隠し、選択を解除します |
| すべて表示 | 面、アイランド、オブジェクトの非表示をすべて解除します |
| このアイランドを隠す / このアイランドだけ表示 | 押した UV アイランドを隠すか、そのアイランドだけを表示します。Scene ビューで右クリックした場所のアイランドに、同じ名前の項目が表示されます |
| 反転 | 面の非表示を裏返します |
| 拡張、縮小 | 隠した面の集合を、面の隣接関係を基準に 1 層ずつ広げるか狭めます |

ウィンドウ上部のステータス行には、非表示の状態が 1 行で表示されます。

- 非表示がない場合は `非表示なし`
- 非表示がある場合は `非表示 {0}%` の形式で、隠した割合が表示されます
- プリセットを読み込んだあとは `プリセット: {0}`（プリセット名）、反転中は `反転済み`

### オブジェクトの目

オブジェクトの一覧には、表面のレンダラーごとに 1 行ずつ表示されます。目のアイコンを押すと、そのオブジェクトの表示が切り替わります。**Alt+クリック** は `これだけ` 表示です。オブジェクトの非表示は、階層のパスで保存されます。

### 非表示のプリセット

- `現在の非表示を保存` で、今の非表示の状態を名前付きで保存します。空の名前は保存されません。プリセットは文書ファイル（`.mpd`）に含まれます。
- 一覧から `読み込み`、`名前を変更`、`削除` を行います。プリセットがない場合は `保存済みのプリセットがありません` と表示されます。
- プリセットは **面の数とアイランドの数が同じメッシュでのみ** 読み込みます。異なる場合は何も変わらず、ステータス行で知らせます。

### 非表示を使うときの注意点

- ストロークの途中では、非表示を変えません。ストロークとストロークの間にだけ変えます。
- どの面も覆わない場所（ガター）は、表示されている側として扱われます。隠したアイランドの縁の外側が描かれることがあります。

## ミラー詳細

ミラー詳細のウィンドウは、[描画](/guides/painting#対称) の対称 X、Y、Z の設定をより細かく合わせます。対称のオン・オフは、`ミラー/X`、`ミラー/Y`、`ミラー/Z` のメニュー、または `ミラー (X)` の項目で行います。

| 項目 | 設定 |
|---|---|
| 中心 | `自動`（モデルから推定）、`原点`（Animator のルートの原点。Animator がない場合はレンダラーのルートの原点）、`手動指定` |
| 手動指定 | X、Y、Z の数値を入力するか、`Scene で点をクリック` で表面の点を指定します。`中心を近い頂点へ` をオンにすると、最も近い頂点に合わせます |
| 許容範囲 | 0～3 %、既定は 1 %。モデルのバウンディングボックスの対角線を基準にした半径です |
| レストポーズ基準 | オンにすると、モデルを読み込んだときの基本姿勢の頂点を基準に、鏡像の位置を計算します。そのデータがない場合は、今の姿勢を使います |
| 反射ストロークを頂点に合わせる | 反射されたストロークの位置を、近い頂点に合わせます。表面スナップがオンのときだけ適用されます |

- 許容範囲は、頂点合わせがオンのときに使われます。
- 不均一なスケール（例: 1、2、1）を持つレンダラーは、軸に揃った平面でのみ正確です。

## ウェイト選択

ウェイト選択は、選んだボーン（骨）のウェイトがある場所を選択範囲にします。ツールウィンドウの一覧から `ウェイト選択` を開きます。

- ボーンの一覧は木構造で表示され、深さに応じてインデントされます。複数のボーンにチェックを付けられます。
- `閾値` は既定で 50 %です。ウェイトの値が閾値を **超える** 場所が選択されます。
- `ウェイトを強度として使う` をオンにすると、ウェイトの値が選択の強さとして使われます。
- `選択への合成` は、`新規選択`、`加算`、`減算`、`交差` のいずれかです。
- `この範囲だけ表示` は、チェックしたボーンのウェイトがある面だけを残し、残りの面を非表示のレイヤーで隠します。選択チャンネルは変わらず、この変更は元に戻すの段階ではありません。
- `選択を適用` で選択を確定し、`すべて解除` でチェックを外します。チェックしたボーンがない場合は `チェックしたボーンがありません` と表示されます。
- メッシュレンダラーがない、またはウェイトがないモデルでは、選択は 0 です。

## 面方向のぼかし

面方向のぼかしは、面に沿って 1 つの方向へ色をにじませます。フィルターのメニューの `面方向ブラー…` から始めます。ぼかしはアクティブなレイヤーにかかり、プレビュー中は他のフィルターを開けません。

1. **方向**: Scene ビューの矢印をドラッグして決めます。既定の方向は -Y です。
2. **長さ**: cm で入力します。モデルの高さに対する % も一緒に表示されます。
3. **両方向**: オンにすると、矢印の両側ににじみます。オフにすると、方向の側だけに集まります。
4. `Enter` で確定、`Esc` でキャンセルです。確定はぼかしの 1 段階で元に戻せます。キャンセルすると、レイヤーは元のピクセルに戻ります。

- **継ぎ目を越えてにじませる**: UV の継ぎ目でつながる面のペアを越えてにじみます。このペアは表面ごとに 1 回計算され、ポーズが変わるとぼかしに使う段階のマップを作り直します。
- 表面がないマテリアルでは、`表面がないため面方向のぼかしを使えません` と表示されます。

![面方向のぼかしのバー](/img/captures/surface-blur-bar.png)

## AO ベイク

AO ベイクは、モデルの周囲の遮蔽を計算して、グレーの結果を作ります。ウィンドウは `レイヤー > AO/ベイク…` から開きます。

| 項目 | 設定 |
|---|---|
| 文書 | ベイクするマテリアルの文書ごとに、`ベイク` と `影を落とす` を別々に選びます |
| 品質 | 32、64、128 方向から 1 つ。方向が多いほど精密ですが、遅くなります |
| 距離 | 3 cm、8 cm、20 cm から選ぶか、数値（cm）を入力します |
| モデルの高さに比例 | オンにすると、距離にモデルの高さ / 160 cm を掛けます |
| 強度、コントラスト | 結果の強さと明暗のコントラストを調整します |
| アルファを考慮 | オンにすると、透明なマテリアル（例: 髪のカード）は、アルファが 0.5 以上の場所だけを遮蔽します |
| 傾斜バイアス | オンにすると、傾いた面の自己影の汚れを減らす深度の余裕を、傾きに合わせます |
| 他の影を無視 | オンにすると、他のオブジェクトが落とす影を計算から除きます |

- `ベイク開始` を押すと、進行の行に `方向 n / m` が表示されます。`キャンセル` を押すと、状態は `待機中` に変わり、結果はレイヤーに書き込まれません。
- すべての文書が終わると、結果は文書ごとに **`AO` レイヤー** になります。レイヤーは乗算の合成モードで入り、文書ごとに元に戻すの 1 段階です。
- `PNG 書き出し` で結果をファイルとして保存します。

## 凹凸（法線）

凹凸ツール（`凹凸(法線)`）は、描いた場所を高さとみなして法線マップを作ります。ツールバーでオンになっています。

### スタンプ 9 種

凹凸ツールのサブツールは次の 9 つです。名前は画面の表示そのままです。

| 番号 | 画面の表示 |
|---|---|
| 1 | 点線へこみ |
| 2 | 凸 |
| 3 | 溝 |
| 4 | 隆起 |
| 5 | クロスステッチ |
| 6 | ジグザグ |
| 7 | リベット |
| 8 | しわ |
| 9 | ふくらみ |

### 凹凸スロット

凹凸ペンの結果は、次の 2 つのうち 1 か所に書きます。

- **既存の法線に重ねる**: 文書の法線スロットに合成します。法線スロットがあるプロファイルでは、既定の設定です。
- **別のスロット**: `スロット名` を決めて、別々に書きます。

法線スロットがないプロファイルでは `このプロファイルには法線スロットがありません` と表示され、`既存の法線に重ねる` は押せません。

法線のスロットがあるのに、法線の文書が開かれていない、または空のマテリアルで凹凸ツールを選ぶと、`法線マップがありません。新しい法線の文書を作成しますか？` と尋ねられます。`作成` を押すと法線の文書を作り、`キャンセル` を押すと何も変わりません。

### 高さを法線に変換するフィルター {#높이를-노멀로-필터}

フィルターのメニューの `高さをノーマルに` は、描いた高さを法線マップに変換するフィルターです。`凹凸の強さ` で傾きを決めます。ほかのフィルターと同じく、プレビューと `Enter` での確定を使います。

## メッシュの再読み込み

モデルのファイルを再読み込みすると、文書は自動的にメッシュを読み直します。ステータス行に次の内容が表示されることがあります。

| 状況 | 結果 |
|---|---|
| UV が変わった | アイランドを再計算します。選択と非表示のプリセットは無効になります |
| 三角形の数が変わった | 非表示を解除して、すべて表示します |
| メッシュを読み込めなかった | `再読み込みしたメッシュを読み込めませんでした: {理由}` と知らせます |

プロジェクトからマテリアルが消えたセットは、[セット](#セットとセットのメモリ) の中で `マテリアルなし` と表示されます。

## MaskMaker 連携

MaskMaker が作ったマスクの PNG を、選択範囲として使います。

1. 選択ツールのメニューから `MaskMaker マスクから…` を選びます。
2. `MaskMaker マスク` のウィンドウで `ファイルを選ぶ…` を押して、PNG を選びます。
3. チャンネル（R、G、B、A）のうち 1 つを選びます。
4. `選択に適用` で、選択に加算するか、新規の選択にします。

- MaskMaker がインストールされていない場合は、`MaskMaker がインストールされていません` と表示されます。
- MaskMaker で開いたセッションが残っている場合は、`MaskMaker セッションを使用中` と表示されます。MaskMaker が保存していない描画を持っている場合、MingPainter は Scene の入力を受け取らず、ステータス行で理由を知らせます。
- `MM 生成結果を読み込む` は、マットキャップ、キャビティなど MaskMaker の出力 PNG を新しいレイヤーとして読み込みます。

## セットとセットのメモリ {#세트와-세트-메모리}

1 つのモデルにマテリアルが複数ある場合、マテリアルごとに文書が開かれます。これらの文書を **セット** と呼びます。

### 自動切替

`自動切替`（Scene ビューのセットの行）をオンにすると、別のマテリアルの上でストロークを始めたときに、そのマテリアルのセットへすぐに切り替わります。開いていないセットは、開きながら `開いています: {名前}` と表示されます。選択範囲がある場合は、別のマテリアルへ移りません。選択を解除すると移ります。

### セットのメモリ

`セットのメモリ` のウィンドウには、開いている文書ごとの GPU メモリの使用量が表示されます。

- 使用中のセットは `GPU {0}`（バイト）と表示されます。
- スリープ中のセットは `スリープ中` と表示されます。
- 一番下の `GPU 合計` は、セットごとの値の合計です。

スリープのルールは次のとおりです。

- アクティブなセットと、その直前のセットは起きたままです。
- それ以外のセットは **30 秒** 使われないとスリープします。スリープすると GPU オブジェクトを下ろし、ピクセルをスリープ用の保存領域へ移します。
- 開いている文書の GPU の推定値がデバイスメモリの **70%** を超えると `GPU メモリ注意`、**90%** を超えると `GPU メモリ危険` と知らせます。

### マテリアルのないセットとレイヤーの移動

プロジェクトからマテリアルが消えたセットは、`マテリアルなし: {名前}` と表示されます。`レイヤーを移動…` を押すと、そのセットの最上位のレイヤー（フォルダーの場合は配下すべて）を、**別の開いているセットへ移動** します。

- `移動するレイヤー` と `移動先のセット` を選び、`移動` を押します。移動先のセットの一番上に、元の順序のまま入ります。移動先のセットの元に戻すの 1 段階です。
- 移動先がカラーチャンネルの文書、またはカラーチャンネルのフォルダーである場合は、拒否されます。
- どちらかのセットで描画中の場合は、`レイヤーの移動` を開始しません。
