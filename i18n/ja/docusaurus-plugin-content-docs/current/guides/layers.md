# レイヤー

**この文書を読むと** レイヤーに合成モードとマスクを付け、調整レイヤーとエフェクトで色を変え、フィルターと自動レイヤー分割を使えるようになります。

レイヤーパネルには、ラスターレイヤー、フォルダー、調整レイヤーが 1 つの一覧で表示されます。

## 合成モード

レイヤーとフォルダーは、合成モード 29 種を使います。Photoshop の 27 種と CSP の 2 種（`発光覆い焼き`、`加算(発光)`）です。合成モードの一覧は 7 つのグループに分けられ、グループの間に区切り線があります。

プロパティの行で合成モードを選びます。その下の行に `塗り` のスライダーがあります。

![合成モードのドロップダウンを開いたレイヤーパネル](/img/captures/layers-panel-blend.png)

## レイヤーマスク

**マスク** は、レイヤーのどこを表示し、どこを隠すかを決めるグレーの画像です。**白は表示、黒は非表示になります。**

### 作成

レイヤーを右クリックするか、レイヤーカードのマスクボタンを押して選びます。

| メニュー | 結果 |
|---|---|
| マスクを追加: すべて表示（白） | 白いマスク |
| マスクを追加: 選択範囲から | 現在の選択範囲がマスクになります |
| マスクを追加: すべて非表示（黒） | 黒いマスク。レイヤーがすべて隠れます |

次の場合はマスクを作れません。メニューが薄く表示され、理由が括弧で示されます。

- レイヤーが選ばれていません。
- カラーチャンネルのフォルダーです。
- ロックされたレイヤーです。
- 元の画像（下地）のレイヤーです。
- 既にマスクがあります。

### マスクを描く

レイヤーの行には、色のサムネイル、リンクアイコン、マスクのサムネイルが順に並びます。

| 操作 | 働き |
|---|---|
| マスクのサムネイルをクリック | マスクに描きます。サムネイルに枠が付きます |
| 色のサムネイルをクリック | 色の描画に戻ります |
| Shift + マスクのサムネイル | マスクを有効・無効にします。無効になると赤い X が表示されます |
| Ctrl + マスクのサムネイル | マスクを選択範囲にします |
| Ctrl + 色のサムネイル | レイヤーの形を選択範囲にします |
| リンクアイコン | マスクがレイヤーに追従して動くかどうかを決めます |

Ctrl の操作に Shift を加えると加算、Alt を加えると減算、Shift と Alt を一緒に押すと交差になります。

マスクを黒で描くと描いた部分が消え、白で描くと戻ります。マスクを描いている間、スポイトはマスクの値ではなく合成された色を拾います。別のレイヤーを選ぶと、自動的に色の描画に戻ります。

レイヤーの消去（`Del`）は、描いている面に従います。マスクの面では、マスクを白で塗りつぶします。

### 適用と削除

- **マスクを適用**: マスクをレイヤーのピクセルに合成し、マスクを取り除きます。通常の（ラスター）レイヤーでのみ行えます。
- **マスクを削除**: マスクだけを取り除きます。レイヤーはそのままです。

どちらの操作も、元に戻すの 1 段階です。

## クイックマスク

`Q` キーでオン・オフします。ツールバーの一番下にあるトグルでも切り替えられます。オンにすると、選択範囲の外が赤い半透明で覆われ、その上に描いて選択範囲を直せます。オフにすると、描いた形が選択範囲になります。

- 描いている間、Scene のステータス行に `クイックマスク` が表示されます。
- 保存した PNG には、赤い重ね描きは入りません。
- クイックマスク中のレイヤーの消去（`Del`）は、選択の解除になります。

![クイックマスクをオンにした状態](/img/captures/layers-quickmask-on.png)

## 塗りの不透明度

`塗り` の不透明度は、エフェクトを除いたレイヤー自体の不透明度です。エフェクト（ドロップシャドウなど）は、塗りを下げても表示されたままです。調整レイヤーとカラーチャンネルのフォルダーでは、スライダーが薄く表示されます。

## 調整レイヤー

調整レイヤーは、その下にあるレイヤーの色を変えます。ピクセルには手を加えません。

| 調整 | 備考 |
|---|---|
| 色相・彩度 | |
| 明るさ・コントラスト | |
| レベル補正 | チャンネルの選択、ハンドル 5 つ、ヒストグラム |
| 反転 | 値はありません。案内の行だけが表示されます |
| 白黒 | |
| ポスタリゼーション | |
| 2階調化 | |
| グラデーションマップ | 制御点の追加・移動・色・削除 |
| トーンカーブ | 点の追加・ドラッグ・ダブルクリックで削除、ヒストグラム |
| カラーバランス | PSD 書き出しでは近似 |
| 特定色域の選択 | PSD 書き出しでは近似 |
| 色の置き換え | PSD 書き出しでは近似 |

**作成**: レイヤーカードの調整レイヤーのボタンを押して、種類を選びます。現在のレイヤーの上、同じフォルダーに作られます。

**値を直すとき**: 調整の行のサムネイルを押すと、調整のウィンドウが開きます。ツールウィンドウのメニューからも開けます。

- スライダーをドラッグしている間、モデルに直接反映されます。ドラッグ 1 回が、元に戻すの 1 段階です。
- `リセット` ボタンで初期値に戻します。
- ヒストグラムは、レイヤーを切り替えたときと、値を離したときに 1 回更新されます。

調整レイヤーの上から下へ結合すると、直下のレイヤーだけに適用されます。調整レイヤーの側へ上方向に結合する操作は拒否されます。

## レイヤーエフェクト

レイヤーエフェクトは 3 種類です。

| エフェクト | 設定 |
|---|---|
| ドロップシャドウ | 角度、距離、広がり、サイズ、色、不透明度、合成モード |
| カラーオーバーレイ | 色、不透明度、合成モード |
| 境界線 | 位置、サイズ、色、不透明度、合成モード |

**開き方**: レイヤーを右クリック → `レイヤーエフェクト…`、またはロックの行の `fx` ボタン。左の一覧でエフェクトをオンにし、右側で値を調整します。

- ドロップシャドウの角度は、影が **動く** 方向です。0 が右で、反時計回りに大きくなります。Shift を押すと 15 度単位で動きます。
- 距離のスライダーは 500 まであります。
- ウィンドウ下部の `すべてオフ` と `すべてオン` は、エフェクトの値を消さずにまとめてオン・オフします。`エフェクトを消去` は、エフェクトの値を取り除きます。
- `エフェクトをラスタライズ` は、エフェクトをレイヤーのピクセルに焼き込みます。不透明度もピクセルに焼き込まれ、レイヤーは 100% になります。
- 調整レイヤーとロックされたレイヤーでは、エフェクトのメニューが薄く表示され、理由が示されます。

![エフェクトのウィンドウ](/img/captures/layers-effects-window.png)

![エフェクト 3 種の適用例](/img/captures/layers-effects-three.png)

## フィルター

ウィンドウの `⋯` メニューから `フィルター` を選びます。フィルターのメニューは 9 項目です。

| フィルター | 主な設定 |
|---|---|
| ぼかし（ガウス） | 半径 |
| ぼかし（移動） | 角度、距離 |
| アンシャープマスク | 半径、量、しきい値 |
| ノイズを加える | 量、ガウス分布、モノクロ |
| メディアン | 半径（整数） |
| モザイク | セルのサイズ |
| ハイパス | 半径 |
| オフセット | 横方向のずれ、縦方向のずれ、反対側へのつなぎ |
| 高さをノーマルに | 凹凸の強さ。描いた高さを法線マップに変換します。[3D 作業](/guides/3d#높이를-노멀로-필터) を参照してください |

フィルターのウィンドウで値を変えると、モデルにプレビューが表示されます。

1. 値を選びます。プレビューのチェックでオン・オフを切り替えます。
2. `Enter` を押すと適用されます。元に戻すの 1 段階です。
3. `Esc` またはウィンドウを閉じると、元に戻ります。

UV アイランドの外には広がりません。プレビュー中は、描画、レイヤーの編集、元に戻すが使えなくなります。アクティブなレイヤーを切り替えるか保存すると、プレビューは自動的に取り消されます。

次の場合はフィルターを使えません。メニューが薄く表示されます。

- レイヤーがない、調整レイヤーである、フォルダーまたはカラーチャンネルのフォルダーである。
- ロックされている、または非表示のレイヤーである。
- マスクの面やクイックマスクを描いている。
- 透明ピクセルのロックがオンのレイヤーである。

![フィルターのウィンドウ](/img/captures/layers-filter-window.png)

## ヒストリーパネル

ヒストリーの行を押すと、その段階に移動します。複数の段階を、元に戻すとやり直しで一度に移動できます。以前の段階は薄く表示されます。フィルターのプレビュー中は、移動できません。

## 複製と結合

| 操作 | キー | 説明 |
|---|---|---|
| 下のレイヤーに結合 | `Ctrl+E` | アクティブなレイヤーを直下のレイヤーと結合します。結果は下のレイヤーの合成モード、不透明度、表示、クリッピングを引き継ぎます |
| 表示レイヤーを結合 | 右クリックメニュー | 同じフォルダー内で **連続している** 表示レイヤーを結合します。間に非表示のレイヤーがあると拒否されます |
| エフェクトをラスタライズ | エフェクトのウィンドウ | 上のレイヤーエフェクトの節を参照してください |

複製は、レイヤーのメニューの `複製` で行います。複製するとマスクも一緒にコピーされます。結合は、元に戻すの 1 段階です。

## レイヤーの自動分割

テクスチャを色と位置のルールで、部位ごとのフォルダーに分けます。衣装のテクスチャ 1 枚を肌、布、飾りに分けて、別々に描きたいときに使います。

**開き方**: ウィンドウの `⋯` メニュー、またはレイヤーの右クリックメニューの `レイヤーを自動分割…`。メニュー `Tools/StudioRaming/MingPainter/Auto Split Layers…` からも開けます。文書がない場合、ピクセルのない文書の場合、カラーチャンネルの文書の場合は、薄く表示されます。

### 手順

1. **入力** を選びます: `元のファイル`、`編集中のキャンバス`、`読み込み結果`。読み込み結果がファイルと異なる場合は、黄色い行で知らせます。
2. **提案** を押します。画像から部位のルールを作ります。現在のルールは置き換えられます。
3. プレビューで `部位色を重ねる` を使って領域を確認します。ホイールで拡大し、中ボタンで移動します。部位を押すと選択されます。
4. 必要に応じてルールを直します。
   - `クリック分割` をオンにしてプレビューを押すと、選んだ部位からその色を切り離して新しい部位にします。
   - `統合`: 部位を 1 つ選び、Ctrl+クリックで 2 つ目を選んで結合します。
   - `名前`、`上`/`下`（優先順位とレイヤーの順序）、色・彩度・明度の許容値を調整します。
5. **適用** を押します。

### 適用すると作られるもの

部位ごとに、フォルダーが 1 つずつ作られます。ルールの順序の最初の部位が一番上に来ます。

- フォルダーにはマスクが付きます。
- フォルダーの中に `元のピクセル`（元の画像からその部位だけを残したもの）と、その上にクリッピングされた空の `塗り` レイヤーがあります。
- 元のレイヤーは非表示になり、一番下に移動します。削除はされません。
- 適用全体が、元に戻すの 1 段階です。

### 設定

| 設定 | 意味 |
|---|---|
| 出力サイズ | マスクの解像度。文書サイズ、1/2、1/4 から選びます。小さくすると輪郭が粗くなります |
| 最小の領域 | これより小さい点状の領域は、隣接する部位に統合します（0 でオフ） |
| 部位ごとに最大の領域を保持 | オンにすると、小さい部位も消えません |

### 作り直し

ルールを変えたあとに `再生成` を押すと、以前の分割で作られたフォルダーを探し、マスクと `元のピクセル` だけを作り直します。`塗り` レイヤーの絵、フォルダーの名前、順序はそのままです。なくなった部位のフォルダーは削除せずに残します。

### ルールの保存と RGB マスク

- `ルール保存…` と `ルール読み込み…` で、ルールをファイルでやり取りします。
- `RGB マスクを書き出す…` は、3 つの部位を R、G、B チャンネルに格納した PNG を保存します。ファイル名は `<元のテクスチャ>_parts<番号>.png` です。
- 最初のシートは、マテリアルのアクティブなテクスチャスロットに接続できます。マテリアルが読み取り専用の場合は接続されず、ファイルだけが保存されます。

## この版にないもの

文書は一辺 4096 ピクセルまでです。ベベルとエンボス、サテン、スマートオブジェクト、16 ビット画像には対応していません。
