# 描画

**この文書を読むと** ツールバーからツールとサブツールを選び、色混ぜと二重の先端を使い、対称と UV の継ぎ目の設定を合わせられます。

描画のツールは **ツールバー** にまとまっています。ツールを選ぶと、そのツールのサブツールとプロパティがブラシのツールウィンドウに表示されます。

![Scene ビューのモデル上のブラシカーソルとストローク](/img/captures/paint-scene-cursor.png)

## ツールバー

| ツール | 既定のキー（CSP） | 既定のキー（PS） | 働き |
|---|---|---|---|
| ペン | `P` | `P` | 線がシャープな絵を描きます |
| 筆 | `B` | `B` | 質感とにじみのある絵を描きます |
| エアブラシ | 既定のキーなし（キー割り当て可能） | 既定のキーなし（キー割り当て可能） | 吹き付けるように塗ります |
| ブラシ集 | 既定のキーなし（キー割り当て可能） | 既定のキーなし（キー割り当て可能） | 鉛筆、木炭、スポンジなど、さまざまな質感のブラシをまとめます |
| 消しゴム | `E` | `E` | 描いたピクセルを消します |
| 塗りつぶし | `G` | `G` | 領域を色やマテリアル全体で塗ります |
| スポイト | `I`、`Alt` を押している間 | `I`、`Alt` を押している間 | 画面の色を取り込みます |
| 色混ぜ（ぼかし・指先・色混ぜ） | `J` | `R` | 描いた色をにじませたり、引きずったりします |
| グラデーション | 既定のキーなし（キー割り当て可能） | 既定のキーなし（キー割り当て可能） | 色が少しずつ変わる面を作ります |
| 図形 | `U` | `U` | 直線、長方形、楕円、曲線を描きます |
| 選択 | `M` | `M` | 描く場所を制限する範囲を選びます |
| 自動選択（魔法の杖） | `W` | `W` | 似た色の領域をまとめて選びます |
| 移動・変形 | `V`、`Ctrl+T` | `V`、`Ctrl+T` | 選んだ絵を移動、拡大、回転します |
| テキスト | `T` | `T` | 文字をレイヤーとして書きます |
| 定規 | 既定のキーなし（定規の切り替えは `Ctrl+Alt+R`） | 既定のキーなし（定規の切り替えは `Ctrl+Alt+R`） | 線がなぞるガイドを作ります |
| デコレーション・スタンプ・パターン | 既定のキーなし（キー割り当て可能） | 既定のキーなし（キー割り当て可能） | 装飾の絵、登録した絵、繰り返しの模様を押します |

:::note[キーは設定で変更できます]
既定のキーは [ショートカット](/reference/shortcuts) の表で確認できます。設定ウィンドウの `ショートカット` で変更できます。→ [設定](/reference/settings)
:::

まだ使えないツールは、ツールバーで薄く表示されます。

## サブツール

**サブツール** は、ツールの中の筆の種類です。ツールごとにサブツールの一覧が異なります。全体の一覧は [サブツール](/reference/subtools) にあります。

たとえばペンツールには、`Gペン`、`丸ペン`、`ミリペン`、`入り抜きペン`、`ベタペン` があります。

## 色混ぜツール

色混ぜツールには、サブツールが 3 つあります。描いた色を混ぜて自然ににじませるときに使います。

| サブツール | 働き |
|---|---|
| ぼかし | 筆が通った場所の色をぼかします |
| 指先 | 筆が通った場所の色を引きずります |
| 色混ぜ | 筆に色をのせて描きます。筆が下の色を拾い、描く色と混ぜます |

色混ぜツールのプロパティは `ぼかし・混色` のセクションにあります。

| プロパティのセクション | プロパティ | 意味 |
|---|---|---|
| ぼかし・混色 | 混ぜ方 | ぼかし、指先、色混ぜ |
| ぼかし・混色 | ぼかし範囲 | ぼかしでどこまで混ぜるか（テクセル単位、最大 32） |
| ぼかし・混色 | 強さ | 指先でどれだけ引きずるか |
| ぼかし・混色 | 拾う範囲 | 色混ぜが色を拾う範囲 |
| 色混ぜ | 絵の具の量 | 拾った色を描く色へ混ぜる度合い |
| 色混ぜ | にじみ | ストロークが長くなっても、拾った色がどれだけ残るか |
| 色混ぜ | 混色方式 | 全体設定、絵の具、デジタル |
| 色混ぜ | 全レイヤーから拾う | オンにすると、表示されている合成色から拾います。オフにすると、描いているレイヤーから拾います |

- `絵の具` 方式は、絵の具のように色が混ざります。黄色と青を混ぜると緑に寄ります。`デジタル` 方式は、色の値をそのまま平均します。`全体設定` は、色のツールウィンドウの混合タブの選択に従います。
- ぼかしと指先は、ストロークの途中で端の部分の一時プレビューを描きません。最後のスタンプは、ストロークを離したときに確定します。
- 指先は UV テクセルの平面で引きずられます。Scene ビューで筆が複数の UV アイランドにかかる場合、筆の中心があるアイランドの側だけが引きずられます。
- 選択範囲があると、ぼかし、指先、色混ぜはすべて選択の中だけで変わります。

## 二重の先端（デュアルチップ）

ブラシのプロパティの `デュアルチップ` セクションで、2 つ目の先端をオンにします。2 つ目の先端が 1 つ目の先端と重なって、線の形を作ります。粗い質感や散らばる線に使います。

| プロパティ | 意味 |
|---|---|
| デュアルチップを使う | オンにすると 2 つ目の先端が使われます |
| サイズ比 | 1 つ目の先端に対する 2 つ目の先端のサイズ（0.05～2 倍） |
| 間隔 | 2 つ目の先端が離れる間隔 |
| 散布効果 | 2 つ目の先端の位置がばらつく度合い |
| 合成方法 | 乗算、比較(暗)、比較(明)、オーバーレイ、リニア高さ、ハードミックス |

- 合成方法はアルファを基準に解釈します。Photoshop の二重ブラシとは形が異なる場合があります。
- 2 つ目の先端の画像は 1 つだけ使います。
- UV の継ぎ目を越えて描くストロークでは、二重の先端は適用されません。

![二重の先端のプロパティと線](/img/captures/dualtip-properties.png)

## ブラシのプロパティ

ツールを選ぶと、ブラシのツールウィンドウにサブツールのプロパティが表示されます。ツールウィンドウ上部の `主要` と `すべて` のタブで、よく使うプロパティだけを表示するか、すべて表示するかを選べます。プロパティはセクションにまとめられています。

| セクション | 含まれるもの |
|---|---|
| ブラシ先端 | 先端の形、硬さ、画像の先端 |
| ブラシサイズと動的 | サイズ、ペン筆圧などで変わるサイズ |
| 不透明度とブラシ濃度 | 不透明度、ブラシ濃度とその動的設定 |
| 間隔と散布 | 間隔、散布 |
| 角度 | 先端の角度、角度の揺らぎ |
| 用紙質感 | 紙の質感 |
| 入り抜き | 始点と終点の細り（テーパー） |
| 補正 | 手ブレ補正の強さ |
| 蓄積 | 重ね塗りの方式 |
| 合成 | 合成に関する設定 |
| 色の揺らぎ | 色の揺らぎ |
| 3D の初期値 | Scene ビューで描くときの初期値 |
| ぼかし・混色 / 色混ぜ / デュアルチップ | 色混ぜツールと二重の先端 |
| 選択 / 塗りつぶし / 図形 / グラデーション | それぞれのツール |

ブラシのプロパティはサブツールごとに別々に保存されます。同じサブツールを調整中に `リセット` を押すと、初期値に戻ります。

ブラシバーのサイズスライダーは、矩形、楕円、投げ縄、多角形、UV アイランド、面、自動選択では表示されません。これらの形はサイズを使わないためです。選択ブラシと選択消しゴムはサイズを使います。

![ブラシのプロパティのウィンドウ](/img/captures/paint-brush-properties.png)

## ペンの筆圧

ペン入力には、Windows の WinTab 経路と Unity のペンイベント経路を使います。ペンが検出されないときは、[トラブルシューティング](/troubleshooting#펜이-감지되지-않는다) を参照してください。

筆圧がサイズと不透明度に与える影響は、サブツールごとに異なります。`ブラシサイズと動的` と `不透明度とブラシ濃度` のセクションで決めます。ペン自体の筆圧補正は、設定ウィンドウの `ペン・入力` タブで行います。→ [設定](/reference/settings)

![設定ウィンドウのペン補正パッド](/img/captures/settings-pen-pad.png)

## 手ブレ補正

ブラシのプロパティの `補正` セクションで強さを決めます。サブツールごとに別々に保存されます。たとえば `入り抜きペン` の既定の補正強さは 0.2 です。

## 対称 {#대칭}

ブラシバーの `対称` メニューで、X、Y、Z 軸の対称をオンにします。片側を描くと、反対側にも同時に描かれます。対称の中心と軸はモデルから推定します。描くカーソルには対称のリングも一緒に表示されます。対称の設定は、ドメインリロードの後も保持されます。

![対称メニューと対称のリング](/img/captures/paint-symmetry.png)

## 裏面まで描く

ブラシのプロパティの `裏面・隠れた面にも描く` をオンにすると、カメラから隠れている面と裏面まで描きます。オフにすると、見えている面だけを描きます。

## UV の継ぎ目を越えて描く

UV キャンバスで描くとき、ストロークは UV アイランドの境界を越えて隣接する面へつながります。モデル上でつながっている 2 つのアイランドにまたがって、一度に描けます。

- 既定でオンになっています。UV キャンバスの `継ぎ目越え` トグルでオン・オフを切り替えます。
- モデルの表面情報があるときだけ動作します。
- 120 度を超えて大きく折れ曲がった面は越えません。

![UV の継ぎ目を越えてつながったストローク](/img/captures/paint-seam-crossing.png)
