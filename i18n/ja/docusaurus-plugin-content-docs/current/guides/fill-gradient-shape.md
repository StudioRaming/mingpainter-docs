# 塗りつぶし・グラデーション・図形

**この文書を読むと** 領域を一度に塗りつぶし、色の停止点でグラデーションを作り、直線と図形を描けるようになります。

## 塗りつぶし

塗りつぶしツール（`G`）には、サブツールが 5 つあります。

| サブツール | 働き |
|---|---|
| アイランド塗り | 押した場所の UV アイランドを塗ります |
| レイヤー全体 | レイヤー全体を塗ります |
| マテリアル全体 | マテリアルが使う UV 領域全体を塗ります |
| 囲った領域 | 線で囲まれた領域を塗ります |
| 多角形塗り | 点を押して作った多角形の中を塗ります |

アイランド塗りとレイヤー全体は、密度と透明ピクセルのロックを反映します。どちらも元に戻すの 1 段階です。

プロパティのセクション `塗りつぶし` には、許容誤差、隙間を閉じる、領域の拡張、アンチエイリアス、アイランド内のみ、参照対象があります。自動選択と同じ名前のプロパティです。→ [選択](/guides/selection)

![塗りつぶしのサブツールとプロパティ](/img/captures/fill-subtools.png)

## グラデーション

グラデーションツールには、既定のキーがありません。ツールを選ぶと、グラデーションのウィンドウも一緒に開きます。ウィンドウを閉じると、ツールを選び直すまで閉じたままになります。

### グラデーションのウィンドウ

上から下へ、ブロックが並びます。

| ブロック | 働き |
|---|---|
| プリセット | 検索欄と `保存`。一覧は最大 5 行まで表示され、中でスクロールします。行を押すと適用され、行の末尾のゴミ箱で削除します。標準のプリセットは削除できません |
| 停止点のバー | 色の停止点を追加、移動、削除します。調整レイヤーのグラデーションマップと同じエディターです |
| 等間隔 / 反転 / 描画色 / クリア | 停止点を等間隔に並べ直す / 左右を反転する / 選んだ停止点を描く色にする（`Alt` で背景色）/ 選んだ停止点を削除する（2 つは残ります） |
| 広がる距離 | 円形のときだけ表示されます。`モデルの高さ %` と `ワールド単位` を切り替えて使います |
| 全体の不透明度 | グラデーション全体の不透明度です |
| 中心位置 | 3D 空間のときだけ表示されます。X、Y、Z の値と `指定`、`クリア` |
| 確定の案内 | プレビュー中だけ、`Enter 確定 · Esc キャンセル` が表示されます |

- 停止点の `クリア` は、停止点が選ばれていて 3 つ以上あるときだけ押せます。`等間隔` と `反転` は 2 つ以上あるときに押せます。
- プリセットの保存では、名前を尋ねるウィンドウが開きます。
- 中心の `指定` を押してから Scene ビューを押すと、その場所が中心になります。`クリア` を押すと、中心がモデル領域の中央に戻ります。
- 右クリックメニューはありません。保存と削除はボタンで行います。

![グラデーションのウィンドウ](/img/captures/gradient-window.png)

### グラデーションのプロパティ

ツールのプロパティの `グラデーション` セクションです。

| プロパティ | 選択肢 |
|---|---|
| グラデーションの形 | 線形、円形、円錐、反射、ダイヤモンド |
| 範囲外 | 端の色を保つ、繰り返し、ミラー |
| 裏面にも適用 | オンにすると、モデルの裏面にも塗ります |
| 適用空間 | サーフェス、3D 空間 |

![円形グラデーションの広がる距離](/img/captures/gradient-radial-spread.png)

### モデル上でハンドルを使って直す

3D 空間のグラデーションでは、Scene ビューにハンドルが表示されます。中心はブランドカラー、外側は白、停止点は停止点の色です。ハンドルをドラッグして、グラデーションの開始位置と終了位置を動かします。円形では外側のハンドルをドラッグすると、広がる距離の値も一緒に変わります。ウィンドウの上ではハンドルは掴めません。UV キャンバスでは、サーフェスのグラデーションが確定を待っている間、中心から終点までの線分とハンドル 2 つが表示されます。

![3D グラデーションのハンドル](/img/captures/gradient-3d-handles.png)

### 描画と確定

グラデーションをドラッグしてプレビューを確認し、`Enter` で確定、`Esc` でキャンセルします。画面には `Enter 確定 · Esc キャンセル` の状態チップが表示されます。

マスクとクイックマスクの面で確定すると、グラデーションは面の値として入ります。色は明るさ（0.299 R + 0.587 G + 0.114 B）に変換されて描かれます。元に戻すは 1 段階です。覆う場所がない場合は、`塗る場所がありません` というメッセージだけが表示されます。

![グラデーションの確定チップと結果](/img/captures/gradient-commit.png)

### 3D でボーンに追従させる

3D 空間のグラデーションは、ボーンに追従させられます。ボーンの経路を選ぶと、現在の線分の位置がそのボーン基準で保存され、ポーズが変わると線分もボーンに沿って動きます。シーンでボーンが見つからない場合、グラデーションはワールド位置に残り、`ボーンをシーンで見つけられないため、グラデーションをワールド位置に置きます` というメッセージが表示されます。

- 平面の UV グラデーションには、ボーン機能はありません。
- ボーンがシーンから消えてから再び現れると、その間に動いた位置は破棄され、以前のボーン基準のオフセットで線分が移動します。既知の制限です。

## 図形

図形ツール（`U`）には、サブツールが 6 つあります。

| サブツール | 形 |
|---|---|
| 直線 | 2 点間の直線 |
| 長方形 | 長方形 |
| 楕円 | 楕円 |
| 多角形 | 辺が複数ある多角形 |
| 曲線 | 2 次曲線 |
| 点で描く曲線 | 点を通る曲線 |

プロパティは `図形の種類`、`塗りつぶし`、`縦横比固定`、`中心から`、`辺の数` です。確定を待っている図形があると、`Enter 確定 · Esc キャンセル` が状態チップとして表示されます。
