# 選択

**この文書を読むと** 選択ツールで描く範囲を決め、選択を合成して整え、自動選択で似た色の領域を選べるようになります。

選択範囲があると、ブラシ、ぼかし、指先、色混ぜは **選択の中だけで** 変わります。

## 選択ツール

選択ツール（`M`）にはサブツールが 8 つあり、自動選択（`W`）がもう 1 つあります。

| ツール | サブツール | 使い方 |
|---|---|---|
| 選択（`M`） | 矩形選択 | ドラッグして長方形を選びます |
| 選択（`M`） | 楕円選択 | ドラッグして楕円を選びます |
| 選択（`M`） | 投げ縄 | ドラッグして自由な曲線で囲みます |
| 選択（`M`） | 多角形選択 | 点を順に押して多角形を作ります。最初の点の近くで離すと閉じます |
| 選択（`M`） | 選択ブラシ | 描いた場所を選択に加えます |
| 選択（`M`） | 選択消しゴム | 描いた場所を選択から除きます |
| 選択（`M`） | UV アイランド | UV アイランドを 1 つ選びます |
| 選択（`M`） | 面 | ドラッグして通った面を選択に加えます |
| 自動選択（`W`） | 自動選択 | 押して似た色の領域を選びます（魔法の杖） |

- **多角形選択**: 点を押すたびにゴム線が追従します。最初の点の近くで離すと閉じられ、選択が確定します。最初の点の近くとみなす範囲は、Scene ビューでは 8 ピクセル、UV キャンバスでは文書の 1%（最小 8 テクセル）です。`Esc` を押すと、描いていた点をすべて破棄します。
- **選択ブラシと選択消しゴム** は、通常の筆と同じように描きます。直線（`Shift`）も同じです。`Alt` を押している間はスポイトになります。サイズのスライダーを使います。
- 他の選択ツールはサイズのスライダーを使わないため、ブラシバーからスライダーが消えます。

Scene ビューでは、矩形、楕円、投げ縄、多角形は、画面上に見えている形をモデルの表面へ移します。表側だけを選ぶ既定の設定では、カメラを向いた、隠れていない面だけが選ばれます。UV キャンバスでは、UV 上の形がそのまま選ばれます。

## 選択のプロパティ

ツールのプロパティの `選択` セクションです。

| プロパティ | 意味 |
|---|---|
| 選択の形 | 矩形、楕円、投げ縄、多角形、ブラシで選択、ブラシで解除、UV アイランド、面、自動選択 |
| 裏面まで貫通 | オフにすると、見えている表面だけを選びます。オンにすると、奥にあるメッシュまで選びます |
| アンチエイリアス | 選択の縁をなめらかにします。オフにすると、縁がはっきり分かれます |

![表面だけと裏面まで貫通の比較](/img/captures/select-through-backfaces.png)

## 修飾キー

選択ツールを押したときに押されていたキーが、選択をどう合成するかを決めます。

| キー | 結果 |
|---|---|
| なし | 既存の選択を新しい選択に置き換えます |
| `Shift` | 既存の選択に加えます |
| `Alt` | 既存の選択から除きます |
| `Shift` + `Alt` | 既存の選択と重なる部分だけを残します（交差） |

`Ctrl` はこの規則を変えません。ドラッグ 1 回が、元に戻すの 1 段階（`選択`）になります。レイヤーのサムネイルを Ctrl+クリックして選択を作るときも、同じ規則です。→ [レイヤー](/guides/layers)

![修飾キーで選択を合成する](/img/captures/select-modifiers.png)

## 自動選択（魔法の杖）

押すと、似た色のつながった領域を選択します。自動選択で使うプロパティは、`塗りつぶし` セクションのものです。

| プロパティ | 意味 |
|---|---|
| 許容誤差 | どれだけ違う色まで同じ領域とみなすか |
| 隙間を閉じる | 領域を分ける細い線の隙間を、何ピクセルまで閉じるか |
| 拡張 | 選んだ領域を縁の方向へ広げます |
| アンチエイリアス | 縁をなめらかにします |
| アイランド内のみ | 押した場所が属する UV アイランドの中に制限します |
| 参照対象 | 現在のレイヤー、すべてのレイヤー |

`アイランド内のみ` をオンにして UV アイランドの外を押すと、何も選ばれず、ステータス行でその旨が知らされます。隙間を閉じる値を大きくすると、計算に時間がかかります。4096 の文書で隙間を閉じる値 2 ピクセルに数秒かかったという測定があります。

![UV アイランド・面の選択と自動選択](/img/captures/select-island-face-wand.png)

## 選択のコマンド

選択があるときに、次のコマンドを使います。選択バーまたはウィンドウの `⋯` メニューの `選択` サブメニューから選びます。

| コマンド | 既定のキー | 働き |
|---|---|---|
| 選択解除 | `Ctrl+D` | 選択をすべて消します |
| 選択範囲を反転 | `Ctrl+Shift+I` | 選択された部分と選択されていない部分を入れ替えます。選択がなければ全体を選択します |
| 拡張 | なし（キー割り当て可能） | 選択を外側へ広げます。値（px）を尋ねます |
| 縮小 | なし（キー割り当て可能） | 選択を内側へ狭めます。値（px）を尋ねます |
| ぼかし | なし（キー割り当て可能） | 選択の縁をなめらかにぼかします。値（px）を尋ねます |
| 塗りつぶし | なし（キー割り当て可能） | 選択の中を描く色で塗ります。`Alt` を押すと背景色になります |
| 削除 | なし | 選択の中を消します |
| 新規レイヤーへ | なし | 選択の中を新しいレイヤーへコピーするか切り取ります |
| すべてを選択 | なし | 文書全体を選択します。選択バーの `その他 ▾` にあります |

- 拡張と縮小は整数 1～1024 ピクセル、ぼかしは 0.1～512 ピクセル（小数点以下 1 桁）です。最後に使った値が覚えられます。初期値は拡張 1、縮小 1、ぼかし 2 ピクセルです。
- **削除**: 色を描いている最中は、選択の中の透明度を消します。マスクを描いている最中は、マスクのその部分を白で塗りつぶします。クイックマスク中は、選択を解除します。
- **新規レイヤーへ**: `コピーして` と `切り取って` から選びます。切り取りは元の場所に穴を残し、新しいレイヤーと穴は 1 段階で元に戻ります。
- `Ctrl+A`（すべて選択）は **複数のレイヤーを選ぶ** 操作です。ピクセル全体を選択するわけではありません。文書全体を選択するには、選択バーの `その他 ▾` にある `すべてを選択` を使います。
- 選択のコマンドは、すべて元に戻すの 1 段階です。

大きな文書では、拡張、縮小、ぼかしに時間がかかります。開発 PC での測定では、4096 の文書で 4～8 ピクセルを処理するのに約 2 秒かかりました。

次の場合はコマンドが薄く表示され、理由が付きます。選択範囲がない（反転を除く）、ロックされたレイヤー、フォルダー、調整レイヤーです。コピーは、ロックされたレイヤーでも行えます。

## 選択バー

選択ツールを使っているとき、または選択があるときに、選択バーが表示されます。Scene ビューではサブツールバーの上に、UV キャンバスでは下のツールバーの右側に表示されます。

まとまりは 4 つです。

1. 解除、反転
2. 拡張、縮小、ぼかし
3. 塗りつぶし、削除
4. 新規レイヤーへ ▾、その他 ▾

`その他 ▾` には、点線表示、すべてを選択、クイックマスクがあります。幅が 320 未満になるとアイコンだけが表示され、名前はマウスを乗せると表示されます。さらに狭くなると行が折り返されます。

## 選択の点線と外側の暗化

UV キャンバスでは、選択の縁に白と黒が交互に動く点線が表示され、選択の外側が 20% 暗く覆われます。選択バーの `その他 ▾` にある `点線を表示` をオフにすると、両方とも消えます。

Scene ビューでは、選択の縁を画面基準の 1px の点線で描きます。ズームに関係なく同じ太さで見えます。既定ではオンです。

文書が 4K 以上の場合、暗い縁が最大 4 テクセルずれることがあります。選択の周囲が 26 万テクセルを超えると、点線は間引かれて表示されます。
