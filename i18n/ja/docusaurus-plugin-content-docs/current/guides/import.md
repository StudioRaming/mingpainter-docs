# 読み込み

**この文書を読むと** ブラシ、パレット、画像ファイルを MingPainter に読み込み、移せなかった設定が何かがわかります。

## 対応形式

| 形式 | 読み込む内容 | 状態 |
|---|---|---|
| `.abr`（Photoshop のブラシ） | プリセット 1 つを、サブツール 1 つへ移します。移せない設定は警告として残します | 実際のファイルの 2 種類の配置（v6.1、v6.2）を読み込みます |
| `.sut`（CLIP STUDIO のサブツール） | 先端の関連情報を読み込みます | 読み込みコマンドから開きます。先端はファイル内のサムネイル画像から作り、設定の対応は推定のため、レポートに「近似」として残します |
| `.gpl`（GIMP のパレット） | 色の一覧 | 対応 |
| 画像（PNG、JPG など） | ブラシの先端画像 | 対応 |
| `.mpbrush`（MingPainter のブラシ） | この製品のブラシファイル | 対応 |
| WebP | 対象外 | デコーダーがないため、非対応です |

## 移せない設定

読み込みでは、元の値をできる限り移します。次の項目は移せず、警告で知らされます。

| 元の設定 | 結果 |
|---|---|
| 傾きの倍率（`tiltScale`） | 移せません |
| 二重ブラシ（`useDualBrush`） | 移さず、保持のみします |
| 色の純度（`purity`） | 移せません |
| 円形度の調整・最小（`roundnessDynamics`、`minimumRoundness`） | ジッターのみ移します。調整と最小は移せません |
| 質感（`useTexture`） | 同じファイル内のパターンを紙の質感として移します。ファイルにパターンがない場合は移せません |

## ブラシライブラリ

読み込んだブラシは、ブラシライブラリに入ります。ライブラリは PC ごとに 1 つで、既定の場所は `%APPDATA%\StudioRaming\MingPainter` の下です。場所は設定の `ライブラリ` タブで変更できます。`既定の場所に戻す` の行で既定の場所に戻せます。→ [設定](/reference/settings#라이브러리)
