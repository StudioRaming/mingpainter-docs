# 2D キャンバス

**この文書を読むと** 3D モデルなしで白紙のキャンバスに絵を描き、その絵をスタンプとして登録するか、モデルやマテリアルに貼れるようになります。

3D モデルなしで白紙のキャンバスに絵を描きます。描くツールは UV キャンバスと同じです。

## 新規作成

ウィンドウの `⋯` メニューから `新しい 2D キャンバス…` を選びます。

- **サイズ**: 長辺が 256、512、1024、2048 のいずれかです。形は正方形、横長、縦長から選びます。横長と縦長は 4:3 の比率で、短辺は長辺の 3/4（64 の倍数）です。12 種類から選びます。
- 既定は 1024×1024 の正方形です。最後に選んだサイズと形を覚えています。
- 選んだサイズは、幅と高さ（px）と比率で表示されます。
- **保存先**: 空欄のままにすると、`Assets/MingPainter/Canvas/` の下に `Canvas_幅x高さ.mpd` として作られます。同じ名前がある場合は番号を付けます。`参照` で別の場所を選べます。
- `Enter` で作成、`Esc` で閉じます。

![2D キャンバスの新規作成ウィンドウ](/img/captures/canvas2d-new-dialog.png)

## キャンバスのウィンドウ

新しいキャンバスは、独自のウィンドウで開きます。

- タイトルバーに、名前、未保存の変更の表示、サイズ、`左右対称` のトグル、`⋯` メニューがあります。
- `左右対称` をオンにすると、絵を左右対称に描きます。
- `⋯` メニューには、ツールウィンドウの一覧、`PNG で保存…`、`キャンバスを閉じる` があります。
- 未保存の変更がある場合は、閉じるときに `保存して閉じる`、`保存しない`、キャンセルを尋ねます。
- 別の文書がアクティブなときは、キャンバスのウィンドウには描かず、`押してこのキャンバスに戻る` ボタンだけが表示されます。間違った文書に描かないようにするためです。
- メインウィンドウの `⋯` メニューにある `開いている 2D キャンバス` のサブ一覧から、開いているキャンバスへ移動できます。
- キャンバスは `.mpd` ファイルとして保存されます。PNG は `PNG で保存…` で別に書き出します。

## 出力

2D キャンバスのウィンドウの `⋯` メニューの `書き出し` で行えることです。

| 項目 | 働き |
|---|---|
| `スタンプとして登録…` | 名前を尋ねて、スタンプの一覧に入れます。`透明な余白を切り取る` は既定でオンです。絵が空の場合は登録しません。一覧は 60 個までです |
| `3D に貼り付け` | このキャンバスの絵を、画面基準でモデルに貼ります。変形の画面投影と同じ方式です。Scene ビューが見つからない場合は、ステータス行で知らせます |
| `UV テクスチャに貼り付け` | 開いているマテリアルの文書に貼ります |
| `下絵を置く…`、`下絵を消す`、`下絵の濃さ` | 参考の絵をキャンバスの下に薄く重ねます。濃さは 25、50、75、100% から選びます。下絵は保存と PNG の書き出しには含まれません |
