# よくある質問

### macOS や HDRP で使えますか？ {#macos나-hdrp에서-쓸-수-있나요}

いいえ。対応範囲は Windows と Built-in（BRP）、URP です。詳しくは [インストール](/getting-started/installation#지원-버전과-파이프라인) にあります。

### 元のテクスチャファイルは変わりますか？ {#원본-텍스처-파일이-바뀌나요}

いいえ。MingPainter は元のテクスチャファイルを上書きしません。保存すると横に `<名前>_paint.png` が作られ、マテリアルのコピー `<マテリアル名>_paint.mat` がその PNG を指します。元のマテリアルは編集されません。元に戻す方法は [保存と復元](/guides/save-recover#원래대로-되돌리기) にあります。

### 保存していない作業は、Unity を閉じて開き直すと消えますか？ {#저장하지-않은-작업이-사라지나요}

復元フォルダに筆ごとの記録が残っていれば、開き直したときに復元できます。復元の方法は [保存と復元](/guides/save-recover#복구) を参照してください。

### 同じ名前のファイルがあるとどうなりますか？ {#같은-이름의-파일이-있으면-어떻게-되나요}

同じ名前の `.mpd` や `_paint.png` が既にあれば上書きせず、名前の後ろに ` 2` を付けます。保存フォルダのルールは [保存と復元](/guides/save-recover#저장-순서와-위치) にあります。
