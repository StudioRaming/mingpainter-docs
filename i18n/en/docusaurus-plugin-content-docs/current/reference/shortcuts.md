# Shortcuts

**After reading this page** you will be able to check the default keys for the painting tools and commands, for each preset.

There are two presets. `CSP` follows the key layout of CLIP STUDIO PAINT, and `PS` follows the key layout of Photoshop. The only difference between the two tables is the blend tool key (`J` and `R`). You can change keys in the `Shortcuts` section of the settings window. → [Settings](/reference/settings#shortcut-assignment)

The tables were generated from the default key settings in the product code. Only commands with a non-empty key are listed.
