# MingPainter

**A tool for painting 3D model textures directly inside the Unity Editor.**

Paint right on the model, and refine with layers and masks without leaving the texture slot. The painting window uses the same tools in two places: the Scene view and the UV canvas.

## What you can do

- **Paint on the model**: Paint straight onto the model surface in the Scene view with pens, brushes, erasers, fills, and colour mixing. → [Painting](/guides/painting)
- **Stack layers**: Use blend modes, masks, adjustment layers, layer effects, and filters. → [Layers](/guides/layers)
- **Select and transform**: Limit where you paint with a selection, and move, stretch, or rotate a floating image. → [Selection](/guides/selection)
- **PSD round trip**: Open a PSD file with its layers and export your work back to PSD. → [PSD](/guides/psd)
- **2D canvas**: Draw on a blank canvas without a 3D model, then register it as a stamp or paste it onto a model. → [2D canvas](/guides/canvas-2d)
- **3D work**: Hide parts of the model, use advanced symmetry, weight selection, AO baking, normal (emboss) painting, and sets for multiple materials. → [3D work](/guides/3d)

## Supported environments

| Item | Support |
|---|---|
| Unity | 2019.4.31f1 to Unity 6 LTS |
| Operating system | Windows |
| Render pipeline | Built-in (BRP), URP |
| Not supported | HDRP, macOS |

For the full installation steps, see [Installation](/getting-started/installation).
