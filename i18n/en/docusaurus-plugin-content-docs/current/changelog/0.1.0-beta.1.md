# Patch notes 0.1.0-beta.1

:::warning[Closed beta]
0.1.0-beta.1 is given to closed beta testers only. Back up your project before you use it. Things may change in the full release.
:::

## Included features

- A painting window that opens from a model texture slot and paints on the Scene view and the UV canvas
- Pen, brush, airbrush, brush collection, eraser, fill, eyedropper, colour mixing, gradient, shape, selection, auto select, move and transform, text, ruler, and decoration, stamp, and pattern tools
- Symmetry, painting across UV seams, and painting on back faces
- Layers, 29 blend modes, raster masks, quick mask, 12 adjustment layers, 3 layer effects, 9 filters, and history
- Automatic layer splitting and RGB mask export
- 3D work: show range (hide) and hide presets, advanced symmetry, weight selection, surface directional blur, AO baking, normal (emboss) stamps in 9 styles and a normal slot, MaskMaker mask selection, mesh re-import, and sets with set memory
- Opening PSD files and exporting to PSD
- Creating a 2D canvas, registering stamps, pasting onto 3D, and pasting into the UV texture
- Importing brushes (`.abr`, `.sut`, `.gpl`, images, `.mpbrush`)
- Saving, recovery records, and reverting to the original texture
- Shortcut presets (CSP, PS) and Korean, English, and Japanese interfaces
