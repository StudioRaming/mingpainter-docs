# 3D work

**After reading this page** you will be able to hide parts of the model so they cannot be painted, align the centre of left-right symmetry, make selections from bone weights, blur along a surface, bake AO, paint normal (bump) maps, and handle several materials as a set.

All features on this page work on the model (the 3D renderer). Most windows open from the tool window list.

## Show range (hide)

Hiding limits where you can paint, **per face (triangle)**. The mesh itself does not change. Only painting, selection, and depth calculations skip the hidden faces.

- Hidden faces cannot be painted. Hidden faces do not block the faces behind them.
- **Hide faces**, **Hide islands**, and **Hide objects** are saved separately. A face is invisible if any of the three hides it.
- Hiding also applies to the UV canvas. UV strokes, flat gradients, and UV shape selections skip hidden areas.

### Keys and commands

The three keys are listed in the [Shortcuts](/reference/shortcuts) table.

| Command | Key | What it does |
|---|---|---|
| Hide selection | `H` | Hides the faces in the selection and clears the selection. `Ctrl+Shift+D` restores the selection. If there is no selection, nothing changes and the status line tells you |
| Show only selection | `Shift+H` | Hides all faces outside the selection. The selection stays |
| Show all | `Alt+H` | Clears all face, island, and object hiding |

The same commands are under `Show range` in the window menu. This menu also has `Hide this island`, `Show only this island`, `Invert`, `Grow`, `Shrink`, and `Open window`.

### Show range window

| Label on screen | What it does |
|---|---|
| Show only selection | Hides the faces outside the selection |
| Hide selection | Hides the selected area and clears the selection |
| Show all | Clears face, island, and object hiding |
| Hide this island / Show only this island | Hides the UV island you clicked, or shows only that island. The Scene view right-click on an island shows an item with the same name |
| Invert | Flips the face hiding |
| Grow, Shrink | Widens or narrows the set of hidden faces by one face-adjacent layer at a time |

The status line at the top of the window shows the hiding state on one line.

- With nothing hidden: `Nothing hidden`
- With something hidden: the percentage hidden, shown as `Hidden {0}%`
- After loading a preset: `Preset: {0}` (the preset name), or `Inverted` while inverted

### Object visibility

The object list shows one row for each renderer on the surface. Click the eye icon to change an object's visibility. **Alt+click** shows that object only. Hidden objects are saved by their hierarchy path.

### Hide presets

- `Save current mask` saves the current hiding state under a name. An empty name is not saved. Presets are saved inside the document file (`.mpd`).
- In the list, use `Apply`, `Rename`, or `Delete`. With no presets, `No saved presets` appears.
- A preset loads only onto a mesh with **the same number of faces and islands**. If the counts differ, nothing changes and the status line tells you.

### Things to know when hiding

- Do not change hiding in the middle of a stroke. Change it between strokes only.
- A gutter where no face covers the area is treated as visible. Areas just outside a hidden island edge can still be painted.

## Advanced symmetry

The advanced symmetry window fine-tunes the X, Y, and Z symmetry settings from [Painting](/guides/painting#symmetry). Turn symmetry on and off with the `Symmetry/X`, `Symmetry/Y`, `Symmetry/Z` menu items, or with `Mirror on (X)`.

| Item | Setting |
|---|---|
| Centre | `Auto` (estimated from the model), `Origin` (the origin of the Animator root, or the root origin of the renderer if there is no Animator), or `Manual` |
| Manual | Enter X, Y, and Z values, or use `Click a point in the Scene` to pick a point on the surface. Turn on `Centre to nearest vertex` to snap to the closest vertex |
| Tolerance | 0 to 3%, default 1%. A radius based on the diagonal of the model's bounding box |
| Rest pose basis | When on, mirror positions are calculated from the rest-pose vertices stored when the model was imported. If that data is missing, the current pose is used |
| Snap mirrored strokes to vertex | Snaps the position of mirrored strokes to the nearest vertex. It applies only while surface snapping is on |

- Tolerance is used when vertex snapping is on.
- A renderer with non-uniform scale (for example, 1, 2, 1) is accurate only on planes aligned with the axes.

## Weight selection

Weight selection turns the areas where the chosen bones have weight into a selection. Open `Weight selection` from the tool window list.

- The bone list is shown as a tree, indented by depth. You can check several bones.
- `Threshold` is 50% by default. Areas where the weight is **above** the threshold are selected.
- When `Use weight as strength` is on, the weight value is used as the selection strength.
- `Combine with selection` is one of `Replace`, `Add`, `Subtract`, or `Intersect`.
- `Show only this range` keeps only the faces with weight from the checked bones, and hides the rest with a hiding layer. The selection channel does not change, and this change is not an undo step.
- `Apply selection` confirms the selection, and `Clear all` clears the checkboxes. With no bones checked, `No bones checked` appears.
- A model with no mesh renderer or no weights gives an empty selection.

![Weight selection window](/img/captures/weight-window.png)

## Surface directional blur

Surface directional blur smears colour in one direction along the surface. Start it from `Surface directional blur…` in the filter menu. The blur applies to the active layer, and no other filter can open while a preview is showing.

1. **Direction**: Drag the arrow in the Scene view. The default direction is -Y.
2. **Length**: Enter it in cm. The window also shows it as a percentage of the model height.
3. **Both ways**: When on, the blur spreads on both sides of the arrow. When off, it gathers only in the arrow's direction.
4. `Enter` applies and `Esc` cancels. Applying is one step of undo. Cancelling returns the layer to its original pixels.

- **Spreads across seams**: The blur crosses pairs of faces connected by a UV seam. These pairs are calculated once per surface, and when the pose changes, the step map used for the blur is rebuilt.
- On a material with no surface, the message `There is no surface for the surface directional blur` appears.

![Surface directional blur bar](/img/captures/surface-blur-bar.png)

## Bake AO

AO baking calculates occlusion around the model and creates a grey result. Open the window from `Layer > AO/Bake…`.

| Item | Setting |
|---|---|
| Documents | Choose `Bake` and `Cast shadow` separately for each material document to bake |
| Quality | One of 32, 64, or 128 directions. More directions are more precise and slower |
| Distance | Choose 3 cm, 8 cm, or 20 cm, or enter a value in cm |
| Scale by model height | When on, multiplies the distance by model height / 160 cm |
| Strength, Contrast | Adjusts the strength and contrast of the result |
| Alpha aware | When on, transparent materials (for example, hair cards) occlude only where alpha is 0.5 or higher |
| Slope bias | When on, adjusts the depth margin to the slope, which reduces self-shadow artefacts on tilted faces |
| Ignore other shadows | When on, shadows cast by other objects are removed from the calculation |

- `Start baking` shows `direction n / m` in the progress bar. `Cancel` changes the state to `Idle`, and the result is not written to the layer.
- When all documents finish, each document gets an **`AO` layer** with the result. The layer uses the Multiply blend, and each document is one step of undo.
- `Export PNG` saves the result as a file.

## Normal (emboss)

The emboss tool (`Emboss (normal)`) treats painted areas as height and creates a normal map. It is turned on in the tool strip.

### Nine stamps

The emboss tool has these nine subtools. The names are the same as on screen.

| Number | On-screen name |
|---|---|
| 1 | Dotted hollow |
| 2 | Convex |
| 3 | Groove |
| 4 | Raised |
| 5 | Cross stitch |
| 6 | Zigzag |
| 7 | Rivet |
| 8 | Pleat |
| 9 | Puffed |

### Normal slot

The result of the emboss pen is written to one of two places.

- **Combine onto the existing normal**: Blends into the normal slot of the document. This is the default for profiles that have a normal slot.
- **Separate slot**: Writes to a separate slot. Name it with `Slot name`.

For profiles with no normal slot, `This profile has no normal slot` appears, and `Combine onto the existing normal` cannot be pressed.

If you pick the emboss tool on a material that has a normal slot but no normal document is open or the document is empty, the question `There is no normal map. Create a new normal document?` appears. Press `Create` to make a normal document, or `Cancel` to change nothing.

### Height to normal filter {#height-to-normal-filter}

The `Height to Normal` filter in the filter menu turns the painted height into a normal map. Use `Bump strength` to set the slope. It uses the same preview and `Enter` to apply as the other filters.

## Reimporting a mesh

When you reimport the model file, the document reads the mesh again automatically. The status line may show these:

| Situation | Result |
|---|---|
| UVs changed | Islands are recalculated. Selections and hide presets become invalid |
| Triangle count changed | Hiding is cleared, so everything is visible |
| The mesh could not be read | Shows `Could not read the reimported mesh: {reason}` |

A set whose material was removed from the project shows as `Material missing` in [Sets](#sets-and-set-memory).

## MaskMaker integration

Uses a mask PNG made in MaskMaker as a selection.

1. Pick `From MaskMaker mask…` from the selection tool menu.
2. In the `MaskMaker mask` window, press `Choose file…` and pick the PNG.
3. Pick one channel (R, G, B, or A).
4. Press `Apply to selection` to add to the selection, or to replace it.

- If MaskMaker is not installed, `MaskMaker is not installed` appears.
- If a MaskMaker session is still open, `A MaskMaker session is active` appears. If MaskMaker has unsaved paint, MingPainter does not take over Scene input and the status line gives the reason.
- `Import MM generator result` brings in MaskMaker output PNGs, such as matcap or cavity maps, as a new layer.

## Sets and set memory {#sets-and-set-memory}

When a model has several materials, a document opens for each material. These documents are called **sets**.

### Auto switch

When `Auto switch` (on the set row of the Scene view) is on, starting a stroke over a different material switches to that material's set right away. A set that is not open yet opens, and shows `Opening: {name}`. If there is a selection, painting does not move to another material. Clear the selection and the switch works again.

### Set memory

The `Set memory` window shows the GPU memory each open document uses.

- A set in use shows as `GPU total {0}` in bytes.
- A sleeping set shows as `sleeping`.
- The `GPU total` at the bottom is the sum of the values for each set.

The sleep rules are below.

- The active set and the set just before it stay awake.
- Other sets go to sleep after **30 seconds** without use. When asleep, their GPU objects are released and their pixels are moved to sleep storage.
- When the GPU estimate for open documents passes **70%** of device memory, `GPU memory warning: {0}` appears. Above **90%**, `GPU memory critical: {0}` appears.

### Orphan sets and moving layers

A set whose material was removed from the project shows as `Material missing: {name}`. Press `Move layers…` to **move** the top-level layers of that set (for a folder, the whole folder) **to another open set**.

- Pick `Layers to move` and `Target set`, then press `Move`. The layers are placed at the top of the target set in their original order. This is one undo step in the target set.
- If the target is a channel document or a channel folder, the move is refused.
- If either set is being painted, `Move layers…` does not start.
